# AIMES 项目指令（ChatGPT Work）

本项目采用 AIMES 治理协议。开始项目变更前，先读取 docs/_governance/adapters/CHATGPT-WORK-ENTRY.md；随后读取 docs/_governance/AIMES-CORE-V1.2.md、项目规则和当前任务相关 Skill。请报告实际读取的文件和无法读取的文件。

遵循 AIMES Skill Registry 的触发条件并按需加载专业 Skill；生成引导词/开发提示词或基于项目知识探索产品方案时，必须先读取 product-manager Skill 并完成项目知识分析，再按需进入需求认知、知识复用或 prompt-optimization。纯提示词改写才可直接进入 prompt-optimization。先确认需求、验收标准、项目基线和已有修改；保护无关用户修改。

不要假定 GitHub 连接器可写或可执行命令，先确认当前模式能力。只报告真实读取、真实修改、真实执行和可复核证据；未执行检查标记 NOT_RUN，阻塞标记 BLOCKED，证据不足标记 UNKNOWN。交付时列出变更、验证、未执行项和限制。
