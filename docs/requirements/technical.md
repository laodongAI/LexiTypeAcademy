# Lexitype Academy 技术需求文档

## 1. 系统架构

### 1.1 前端架构

Lexitype Academy 采用现代化的前端架构，基于 React 18+ 和 TypeScript 构建，使用 Vite 作为构建工具。系统采用模块化设计，组件和服务分离，职责清晰。

#### 1.1.1 核心组件

- **App.tsx**：应用入口，管理全局状态和路由
- **CourseManager.tsx**：课程管理中心，负责课程列表、筛选、导入导出
- **CourseLessonPractice.tsx**：句子级课程练习，支持多种练习模式
- **WordLessonPractice.tsx**：单词级课程练习
- **GameCenter.tsx**：游戏化学习中心
- **AILab.tsx**：AI 功能实验室

#### 1.1.2 状态管理

- React Hooks：用于组件内部状态管理
- Context API：用于跨组件状态共享
- LocalStorage/IndexedDB：用于持久化存储

### 1.2 服务层架构

#### 1.2.1 课程管理服务

- **courseStore.ts**：课程数据存储与管理
- **courseFactory.ts**：课程生成工厂
- **progressService.ts**：学习进度跟踪
- **reviewService.ts**：复习内容管理

#### 1.2.2 音频处理服务

- **ttsManager**：文本转语音服务，支持多种 TTS 提供商
- **asrManager**：自动语音识别服务，基于 Sherpa-ONNX
- **audioRecorder.ts**：音频录制功能
- **playbackController.ts**：音频播放控制
- **speechEvalService.ts**：语音评估服务

#### 1.2.3 AI 服务

- **aiService.ts**：AI 语义分析服务
- **aiDialogueService.ts**：AI 对话服务

### 1.3 数据模型

#### 1.3.1 课程数据模型

```
Course (课程)
├── id, title, description, tags, difficulty, type
├── stats (学习统计)
└── lessons (课时列表)
    └── Lesson (课时)
        ├── content, contentTranslation
        ├── sentences (句子列表)
        ├── words (单词列表)
        ├── modesEnabled (支持的练习模式)
        └── audio (音频元数据)
```

## 2. 核心功能技术实现

### 2.1 音频处理技术

#### 2.1.1 TTS 实现

- 支持多种 TTS 提供商（SystemTtsProvider、SherpaOnnxProvider）
- 音频缓存机制，提高性能
- 支持语速调节

#### 2.1.2 ASR 实现

- 基于 Sherpa-ONNX 实现本地语音识别
- 支持 VAD（语音活动检测）
- 支持多种语言模型

#### 2.1.3 语音评估

- 实时语音评估
- 提供综合评分、流畅度评分、完整度评分
- 支持发音反馈

### 2.2 学习进度跟踪

- **课程进度**：跟踪每门课程的学习进度，记录已完成的课时
- **单词掌握度**：跟踪每个单词的掌握程度，基于记忆曲线生成复习内容
- **学习统计**：记录学习时间、准确率、WPM 等统计数据

### 2.3 练习模式实现

#### 2.3.1 听写模式

- 音频播放控制
- 实时文本比对
- 错误高亮显示
- 语义相似度提示

#### 2.3.2 跟读模式

- 音频播放与录音控制
- 语音评估
- 发音反馈
- 录音回放

#### 2.3.3 翻译模式

- 文本比对
- 语义相似度分析
- 翻译建议

#### 2.3.4 模仿模式

- 音频比对
- 发音评估
- 语调分析
