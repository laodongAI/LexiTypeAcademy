## 1. 背景与目标

### 1.1 背景

LexiType Academy 作为综合英语学习平台，已具备打字练习、课程播放（基于 TTS）、本地 Sherpa ASR/TTS 能力，以及统一课程数据模型（`courseFactory`）。现有功能支持多种课程生成方式，包括音频导入、AI 生成、PEP 教材导入和补救课程生成。这些基础能力为构建"听说读写 + 复习"闭环提供了坚实支撑。

**用户痛点**：学习内容碎片化、缺乏个性化纠错、复习效率低、课程生成不灵活、列表过滤不足、布局不直观、进度跟踪不清晰、评测不全面。

**解决方案**：结合现有系统，通过 AI 文生文/句/词增强，实现从教材解析到个性化课程的自动化流程，支持沉浸式学习体验。基于最新用户反馈，进一步优化课程创建支持导入/导出（现有代码已实现），详细描述跟读流程，并补充学习进度跟踪（进度可视化、热力图）和学习评测（多维度评分、报告生成）。

### 1.2 目标

**核心目标**：打造覆盖"听说读写"四大能力的闭环学习体系，让用户从"敢开口"到"越说越准"，通过错误驱动生成补救课程，提升学习效率 30% 以上。

**用户目标**：
- K12 学生（80%）：教材同步 + 游戏化复习 + 成就勋章激励
- 成人用户（20%）：场景口语 + 个性化路径 + 社交分享
- 整体：学习动机激励（成就勋章、排行榜、分享）、效率提升（技能雷达图、每日热力图）

**产品目标**：
- 7 天留存率 > 55%
- 30 天留存率 > 35%
- 付费转化率 > 15%（通过 AI 课程生成和复习模块）

**技术目标**：
- 复用现有 TTS/ASR 和课程模型
- 性能：响应时间 < 500ms，内存占用 < 200MB
- 支持离线/在线无缝切换

### 1.3 适用范围

- **用户群体**：K12 学生、成人基础学习者
- **设备**：Electron 桌面端（Windows/Mac），优先本地能力（Sherpa），云端兜底（豆包/WhisperX）
- **语言**：纯中文界面，内容为英语 + 中文翻译

### 1.4 术语定义

| 术语 | 定义 |
|------|------|
| **课程** | Course 对象，包含 Lessons（课时），每个 Lesson 有 Words/Sentences |
| **补救课程** | 基于错误生成的复习课程 |
| **学习路径** | 用户个性化路线（A1-C1 CEFR 级别） |
| **练习模式** | 听写、跟读、翻译、填空、复述 |
| **课程导入/导出** | 支持 JSON/XML 格式导入现有课程数据，导出为可分享文件 |
| **学习进度** | 实时跟踪课程/课时/句子进度，支持可视化热力图 |
| **学习评测** | 多维度评分（准确性、流利度、完整性），生成报告 |

## 3. 功能模块设计

### 3.1 课程管理模块

#### 3.1.1 课程类型

| 课程类型 | 代码标识 | 适用场景 | 数据结构 |
|----------|----------|----------|----------|
| 文本课程 | `text` | 句子/段落练习 | `{ text, translation, audioFile }` |
| 词汇课程 | `words` | 单词记忆、听写 | `{ word, phonetic, pos, definition, example }` |
| 音频课程 | `audio` | 听力练习、跟读 | `{ audioFile, timestamps, transcript }` |
| 混合课程 | `mixed` | 综合练习 | 以上组合 |

#### 3.1.2 课程来源

```
课程来源
├── AI 主题生成
│   ├── 自由主题（用户输入关键词/场景）
│   ├── 弱项生成（基于复习队列）
│   └── 风格模式（对话/故事/新闻/学术）
├── 教材导入
│   ├── PEP 教材体系（小学）
│   ├── 自定义教材解析
│   └── 单元结构识别
├── 文件导入
│   ├── 音频导入（MP3/WAV + 字幕）
│   ├── JSON/CSV 批量导入
│   └── 文本粘贴解析
└── 系统生成
		└── 复习弱项自动生成
```

#### 3.1.3 存储结构

```
data/
├── courses/
│   └── {courseId}/
│       ├── course.json          # 课程元数据
│       └── lessons/
│           └── {lessonId}.json  # 课时数据
└── audio/
		└── {courseId}/
				└── {lessonId}/
						├── main.mp3         # TTS 生成音频
						└── segments/        # 分句音频片段
```

### 3.2 教材体系导入模块（AI 驱动）

#### 3.2.1 业务流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│ Step 1      │ →  │ Step 2      │ →  │ Step 3      │ →  │ Step 4      │
│ 选择教材体系 │    │ 解析单元结构 │    │ 选择生成类型 │    │ 生成与保存  │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

#### 3.2.2 Step 1: 选择教材体系

**界面交互**：
- 下拉菜单：出版社 → 教材系列 → 适用学段
- 示例配置：
	- 出版社：人民教育出版社
	- 教材系列：PEP英语
	- 适用学段：小学（G1-G6）
- 操作：[保存常用组合] 可命名保存，如"人教PEP小学"

**AI 调用**：
```
提示词模板：
"请列出{publisher}{series}教材的完整目录结构，按年级和学期输出教材名称"

输出格式（JSON）：
{
	"textbooks": [
		{ "grade": "G3", "semester": "上册", "name": "英语三年级上册" }
	]
}
```

#### 3.2.3 Step 2: 解析单元结构

**界面交互**：
- 树形控件展示已选教材的单元列表（支持展开/折叠）
- 示例展示：
	```
	英语三年级上册
	├─ Unit 1: Hello
	├─ Unit 2: Colours
	└─ Unit 3: Animals
	```
- 操作：[解析单元]（单本）或 [批量解析]（多本）

**AI 调用**：
```
提示词模板：
"请分析《{textbook_name}》的目录，列出所有单元信息"

输出格式（JSON）：
{
	"units": [
		{ "unit_num": 1, "title": "Hello", "topics": ["greetings", "introductions"] }
	]
}
```

#### 3.2.4 Step 3: 选择生成类型

**界面交互**：
- 多选矩阵：
	- 横向：勾选单元（Unit 1, Unit 2...）
	- 纵向：勾选课程类型（单词课、句子课、音标课）
- 高级选项：
	- 生成粒度：基础词汇 / 拓展词汇
	- 句型难度：简单对话 / 复杂句型
	- AI 补全：音标 / 例句 / 翻译

**课程类型 AI 提示词**：

| 课程类型 | 提示词要点 | 输出字段 |
|----------|------------|----------|
| 单词课 | 核心词汇+拓展词汇+教材例句 | `word, phonetic, pos, zh, example` |
| 句子课 | 核心句型+中文翻译+场景标签+替换练习 | `en, zh, scene, substitution` |
| 音标课 | 目标音标+发音要领+例词+最小对立对 | `target_sound, pronunciation, examples, minimal_pairs` |

#### 3.2.5 Step 4: 生成与保存

**进度可视化**：
```
[✓] 选择教材 → [✓] 解析单元 → [⚙️] 生成内容 → [ ] 完成

日志输出：
→ 2025-12-08 12:00: 开始解析《人教PEP英语三年级上册》
→ 2025-12-08 12:01: 识别到 6 个单元
→ 2025-12-08 12:02: 正在生成 Unit 1 单词课...
→ 2025-12-08 12:03: Unit 1 单词课生成完成（15 词）
```

**结果管理界面**：
```
✅ 成功生成 18 门课程
├─ 单词课程：G3上-U1, U2, U3
├─ 句子课程：G3上-U1, U2
└─ 音标课程：G3上-U1

[批量发布] [导出 JSON] [返回修改]
```

### 3.5 复习系统模块

#### 3.5.1 复习调度算法

```
复习队列生成逻辑：
1. 从 reviewService 获取 due 列表（到期需复习项）
2. 按 priority = severity * (1 - mastery) * timeFactor 排序
3. 队列组成：70% 弱项 + 30% 新内容
4. 每次复习后更新 nextReviewDate（间隔重复算法）
```

#### 3.5.2 错误分类体系

| 错误类型 | 代码 | 描述 | 权重 |
|----------|------|------|------|
| 拼写错误 | SPELLING | 字母/顺序错误 | 1.0 |
| 词义错误 | VOCAB_MEANING | 用词不当 | 1.2 |
| 语法错误 | GRAMMAR | 时态/语态/单复数 | 1.5 |
| 发音问题 | PRONUNCIATION | 发音不准确 | 0.8 |
| 听力问题 | LISTENING | 听辨错误 | 1.0 |
| 语义不当 | SEMANTIC_INAPPROPRIATE | 表达不地道 | 1.3 |
| 流利度 | FLUENCY | 停顿/重复过多 | 0.6 |

## 5. 数据模型与存储

### 5.1 核心数据结构

```typescript
// 课程结构（courseFactory 输出）
interface Course {
	id: string;
	title: string;
	type: 'text' | 'words' | 'audio' | 'mixed';
	source: 'AI Generated' | 'PEP' | 'Audio Import' | 'JSON Import' | 'Remedial';
	modesEnabled: ('dictation' | 'follow' | 'translation' | 'imitation' | 'flashcard')[];
	lessons: Lesson[];
	metadata: {
		createdAt: string;
		updatedAt: string;
		difficulty: 'beginner' | 'intermediate' | 'advanced';
		tags: string[];
		textbookRef?: { publisher: string; series: string; grade: string; unit: string };
	};
	stats: {
		totalItems: number;
		completedItems: number;
		accuracy: number;
	};
}

// 课时结构
interface Lesson {
	id: string;
	courseId: string;
	fields: {
		text?: string;
		translation?: string;
		word?: string;
		phonetic?: string;
		pos?: string;
		definition?: string;
		example?: string;
	};
	audioMeta?: {
		file: string;
		duration: number;
		timestamps?: { start: number; end: number; text: string }[];
	};
}
```

### 5.2 存储路径规范

| 数据类型 | 存储路径 | 格式 |
|----------|----------|------|
| 课程元数据 | `data/courses/{courseId}/course.json` | JSON |
| 课时数据 | `data/courses/{courseId}/lessons/{lessonId}.json` | JSON |
| TTS 音频 | `data/audio/{courseId}/{lessonId}/main.mp3` | MP3 |
| 分句音频 | `data/audio/{courseId}/{lessonId}/segments/{index}.mp3` | MP3 |
| 用户录音 | `data/recordings/{sessionId}/{lessonId}.webm` | WebM |
| TTS 缓存 | IndexedDB (`tts-cache`) | ArrayBuffer |

## 6. 质量控制与容错

| 风险场景 | 应对方案 |
|----------|----------|
| AI 生成内容超纲 | 预置课标词库校验，过滤非课标词汇 |
| 音标标注错误 | 接入权威音标数据库二次校验 |
| 单元解析遗漏 | 提供"手动补充单元"入口 |
| 生成中断 | 自动保存草稿，支持断点续生成 |
| 网络不可用 | 本地 Sherpa TTS/ASR 兜底 |
| 音频播放失败 | 自动重试 2 次，失败后显示文本 |
| 数据不一致 | 保存前结构校验，原子性写入 |
