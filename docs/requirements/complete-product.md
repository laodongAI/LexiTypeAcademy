# Lexitype Academy 完整产品需求文档

## 1. 产品概述

Lexitype Academy 是一个基于 React + TypeScript 构建的语言学习应用，支持 Electron 桌面端，提供英语听、说、读、写全方面的学习功能。系统采用模块化架构设计，支持多种学习模式和音频处理功能，打造一个覆盖“听、说、读、写”四大能力、可持续迭代的 AI 辅助英语学习与复习体系。

## 1.4 术语定义

- "学习单元"：最小内容实体 (词汇、短语、句子、段落)。
- "掌握度"：系统为某单元动态计算的评分 (0–100)。
- "错误分类"：按类型拆分 (拼写、语义、语法、发音、听力识别、使用场景)。
- "复习队列"：基于间隔算法和错误权重生成的下一批练习单元列表。
- "功能语块"：具有特定功能的固定短语或句子片段 (如 "I'm sorry to hear that")。
- "CEFR"：欧洲共同语言参考标准，用于评估语言能力水平 (A1–C1)。
- "ASR"：自动语音识别 (Automatic Speech Recognition)。
- "TTS"：文本转语音 (Text-to-Speech)。
- "VAD"：语音活动检测 (Voice Activity Detection)。
- "Shadowing"：影子跟读，一种语言学习方法，即听到语音后立即模仿跟读。

### 1.1 背景与愿景

目标愿景:
- 构建一个以学员错误数据驱动、动态生成学习内容的自适应平台。
- 让“内容类型 × 学习方式”形成网状组合，任意交叉，避免单一模式疲劳。
- 引入 ASR、语音评分、语法纠错、语义理解等多种 AI 能力，降低人工教研成本。
- 提供可量化、阶段性成长曲线与掌握度图谱 (词汇 / 短语 / 语法结构)。

### 1.2 当前现状 (Baseline)
| 维度 | 已有 | 不足 |
|------|------|------|
| 内容类型 | 单词 (Word), 句子 (Sentence), 文章 (Article) | 短语/固定搭配、功能语块、话题段落缺失 |
| 学习方式 | 读 (打字+阅读), 听 (TTS 播放) | 说 (口语输出)、写作智能反馈不足 |
| 错误跟踪 | 仅部分记录打字错误或回答情况 | 未区分“词汇错误/发音错误/语法错误/用法错误”分类维度 |
| 复习机制 | 基础重复或简单记忆曲线 | 缺少自适应间隔 (基于错误权重与掌握度模型) |
| 内容生成 | 基础 AI 生成课程 (需手工筛选) | 生成质量与可控性、难度分层与 CEFR 标记缺失 |
| 反馈 | 简单正确/错误 | 未给出针对性讲解、例句拓展、语法/发音建议 |

### 2.2 练习功能

#### 2.2.1 学习方式组合矩阵
| 内容 \ 方式 | 听 | 说 | 读 | 写 |
|-------------|----|----|----|----|
| 单词 | TTS+拼写听写 | 朗读+发音评分 | 打字拼写 | 造句/联想写词组 |
| 短语 | TTS 跟读 | 口语模仿/角色扮演 | 语块替换练习 | 语法重组或改写 |
| 句子 | 听写填空 | 复述/连贯组织 | 跟打+语法标注 | 改错/续写 |
| 段落 | 主旨抓取/听力理解 | 口述总结 | 精读标注/关键词抽取 | 摘要写作/观点扩展 |

#### 2.2.2 具体练习模式
- 听写模式：根据听到的音频输入文本
- 跟读模式：播放音频后进行跟读，系统进行语音评估
- 翻译模式：根据中文翻译输入英文
- 模仿模式：模仿目标音频的发音和语调
- Listen First：播放 → 展示文本(可延迟) → 操作
- Type While Listen：循环播放 → 用户实时打字 → 匹配
- Shadowing Loop：播放原音 → 倒计时 → 用户跟读录音 → 对齐反馈
- Gradual Reveal：播放 → 显示首字母/下划线 → 用户猜测 → 完整显示
- Hint Tiered Playback：用户失败次数 k → 播放慢速 → 播放分词 → 播放拼写朗读
- Speak Then Check：用户先说 → ASR 文本 → 与目标比对 → 播放标准语音
- Write Then Voice：用户写句子 → TTS 播放其句子 → AI 建议改写 → 朗读改写
- Batch Review Carousel：按复习队列水平滑动 → 每个单元支持快速播/跟读/打字

### 2.3 音频处理

- 文本转语音（TTS）
- 自动语音识别（ASR）
- 语音评估
- 音频录制和播放
- 支持多轮循环(原音 ↔ 用户)，每轮评分曲线
- 同时展示“我的录音 vs 标准音”对比波形/能量条
- 支持播放模式切换：普通 → 慢速(0.85x) → 分词/拼读 → AB分段(句子分子句)

### 2.1 课程管理

## 课程导入模块

### 2.1.1 模块概述

英语课程导入模块支持两大入口：AI导入、语音文件导入，导入后课程以“课程-课程单元”为核心结构存储，关联语音资源及课程属性信息，同时支持课程导出、导入分享及基础维护操作。

### 2.1.2 核心导入功能需求

#### 2.1.2.1 AI导入（三种模式）

##### 2.1.2.1.1 模式一：AI生成文本构建课程

**核心流程**：
1. 调用AI模型生成英文文本
2. 将文本分割为独立句子
3. 提取核心单词
4. 完成单词翻译、释义及关联例句生成
5. 完成句子翻译
6. 组装为完整课程

**课程结构**：
- 一级为课程
- 二级包含单词列表、句子列表，列表内按对应类别整理内容

##### 2.1.2.1.2 模式二：AI检索出版社课程构建课程

**核心流程**：
1. 调用AI模型检索已对接出版社资源
2. 选择目标出版社及对应课程系列（此步骤核心为AI搜索）
3. 定位具体课程（对应某本书）及所属单元
4. 从单元中拆解出句子、词汇、语法三类核心要素
5. 组装为系统兼容格式并导入

**现有实现**：
- 系统已实现PEP（人教版）课程导入功能，通过解析PEP格式文本提取单元信息、单词、句子和字母
- 支持中英文双向词汇解析，生成单词课程和句子课程
- 支持自定义课程标题策略

##### 2.1.2.1.3 模式三：用户粘贴文本构建课程

**核心流程**：
1. 用户自由粘贴大段英文文本
2. 系统对文本进行句子分割
3. 提取单词及生成对应翻译、释义、例句
4. 生成包含单词列表、句子列表的课程

**与模式一的区别**：
- 文本由用户提供而非AI生成
- 后续分割、提取、翻译等步骤与模式一一致

#### 2.1.2.2 语音文件导入

**核心流程**：
1. 导入大段语音文件
2. 提取文件中字幕信息并转换为句子
3. 将句子翻译为中文
4. 提取句子中核心单词
5. 构建包含单词（含翻译、音标、例句）的词库
6. 按规则组装为课程

**语音关联规则**：
- 与AI导入生成的课程区分，语音导入的句子需关联原语音文件
- 记录对应内容的开始时间与截止时间
- 通过类别标签明确区分

### 2.1.3 课程存储与资源管理

#### 2.1.3.1 存储结构

##### 2.1.3.1.1 数据存储

- **数据存储**：课程基础信息、单元信息、单词及句子详情等数据存储于浏览器数据库
- **语音存储**：所有语音文件（含TTS生成文件、原语音文件）统一存储于data目录，按课程结构规则规划存储路径

##### 2.1.3.1.2 TTS生成规则

- AI导入生成的课程默认无语音，需调用TTS生成对应语音文件并存储
- 首次生成后，系统读取时优先调用已存储文件
- 若文件不存在则重新调用TTS生成并补存

##### 2.1.3.2.1 核心属性

### 2.1.6 技术实现细节

#### 2.1.6.1 数据模型

##### 2.1.6.1.1 核心数据结构

**课程（Course）**：
```typescript
interface Course {
  id: string; // 课程ID
  title: string; // 课程标题
  description?: string; // 课程描述
  tags: string[]; // 课程标签
  difficulty: 'beginner' | 'intermediate' | 'advanced' | 'custom'; // 课程难度
  type: 'text' | 'words' | 'mixed' | 'audio'; // 课程类型
  lessons: Lesson[]; // 课程包含的课时列表
  createdAt: string; // 创建时间
  updatedAt: string; // 更新时间
  stats: CourseStats; // 课程统计数据
  source?: string; // 课程来源
  wordCount?: number; // 课程单词总数
  sentenceCount?: number; // 课程句子总数
  audioFiles?: Array<{ // 课程关联的所有音频文件列表
    lessonId: string;
    fileName: string;
    fileUrl: string;
    sizeBytes: number;
  }>;
  // 扩展属性（需补充）
  targetAudience?: string[]; // 适用人群
  learningGoals?: string[]; // 学习目标
}
```

**课时（Lesson）**：
```typescript
interface Lesson {
  id: string; // 课时ID
  content: string; // 原始文本或词汇串
  contentTranslation?: string; // 中文对照文本
  words?: WordEntry[]; // 词汇列表（若为词汇型课程）
  sentences?: Sentence[]; // 句子列表
  segments?: SegmentItem[]; // 音频片段列表
  language: 'zh' | 'en'; // 语言类型
  length: number; // 内容长度
  source?: string; // 来源
  modesEnabled: PracticeMode[]; // 支持的练习模式
  fields?: {
    phonetic?: boolean; // 是否包含音标
    example?: boolean; // 是否包含例句或扩展示例
    translation?: boolean; // 是否包含整段或句子翻译
    audioEnabled?: boolean; // 是否启用音频功能
  };
  audio?: AudioMeta; // 原始音频信息
  courseId?: string; // 关联的课程ID
  lessonType?: LessonContentType; // 课时内容类型（句子/单词）
}
```

**句子（Sentence）**：
```typescript
interface Sentence {
  id: string; // 句子ID
  en: string; // 英文句子
  zh: string; // 中文翻译
  keywords?: Array<{
    word: string;
    phonetic?: string;
    meaning?: string;
  }>; // 关键词列表
  audioUrl?: string; // 相对路径: audio/{courseId}/{lessonId}/{fileName}
  startMs?: number; // 开始时间（毫秒）
  endMs?: number; // 结束时间（毫秒）
  generated?: boolean; // 是否为生成内容
  source?: 'asr' | 'user_edited' | 'ai_refined' | 'manual'; // 来源
  conf?: number; // 置信度
  labels?: string[]; // 标签，如 ['重点句','难点句','范文句']
  notes?: string; // 教学备注
}
```

**音频元数据（AudioMeta）**：
```typescript
interface AudioMeta {
  sourceType: 'uploaded' | 'tts' | 'external'; // 音频来源类型
  originalFileName: string; // 原始文件名
  fileUrl: string; // 相对路径: audio/{courseId}/{lessonId}/{fileName}
  durationMs: number; // 音频时长（毫秒）
  waveformCache?: number[]; // 波形缓存
  transcriptionModel?: string; // 转录模型
  tracks?: Array<{
    language: string;
    offsetMs?: number;
  }>; // 音轨信息
  sizeBytes?: number; // 文件大小（字节）
  lastModified?: string; // 最后修改时间
  checksum?: string; // 文件校验和，用于验证完整性
  originalFileUrl?: string; // 临时URL，用于上传文件
}
```

**课程统计数据（CourseStats）**：
```typescript
interface CourseStats {

  lastPracticed?: string; // 最后一次练习时间
  progress?: number; // 课程进度（0-100）
  completedLessons?: string[]; // 已完成课时ID列表
  lastLessonId?: string; // 最后练习的课时ID
  sentencesPerfect?: number; // 完美完成的句子数量
  sentencesHigh?: number; // 高分完成的句子数量
  sentencesNeedsReview?: number; // 需要复习的句子数量
```

   - 完善音频文件清理机制，定期清理过期或不再使用的音频文件
   - 实现音频文件校验和验证，确保文件完整性

### 2.2 练习功能

#### 2.2.1 练习模式

##### 2.2.1.1 听写模式
- **核心机制**：根据听到的音频输入文本
- **设计思路**：通过听写练习强化听力理解和拼写能力

##### 2.2.1.2 跟读模式
- **核心机制**：播放音频后进行跟读，系统进行语音评估
- **设计思路**：通过跟读练习强化口语发音和语调模仿能力

##### 2.2.1.3 翻译模式
- **核心机制**：根据中文翻译输入英文
- **设计思路**：通过翻译练习强化中英文转换能力

##### 2.2.1.4 模仿模式
- **核心机制**：模仿目标音频的发音和语调
- **设计思路**：通过模仿练习强化语音模仿能力

##### 2.2.1.5 Listen First 模式
- **核心机制**：播放 → 展示文本(可延迟) → 操作
- **设计思路**：先听后练，强化听力理解能力

##### 2.2.1.6 Type While Listen 模式
- **核心机制**：循环播放 → 用户实时打字 → 匹配
- **设计思路**：边听边练，强化听力理解和实时反应能力

##### 2.2.1.7 Shadowing Loop 模式
- **核心机制**：播放原音 → 倒计时 → 用户跟读录音 → 对齐反馈
- **设计思路**：通过影子跟读练习强化口语流畅度和语音模仿能力

##### 2.2.1.8 Gradual Reveal 模式
- **核心机制**：播放 → 显示首字母/下划线 → 用户猜测 → 完整显示
- **设计思路**：通过渐进式提示强化词汇记忆和拼写能力

##### 2.2.1.9 Hint Tiered Playback 模式
- **核心机制**：用户失败次数 k → 播放慢速 → 播放分词 → 播放拼写朗读
- **设计思路**：根据用户失败次数提供不同级别的提示，降低学习难度

##### 2.2.1.10 Speak Then Check 模式
- **核心机制**：用户先说 → ASR 文本 → 与目标比对 → 播放标准语音
- **设计思路**：先练习后反馈，强化口语表达能力

##### 2.2.1.11 Write Then Voice 模式
- **核心机制**：用户写句子 → TTS 播放其句子 → AI 建议改写 → 朗读改写
- **设计思路**：通过写作练习强化写作能力，并提供AI改写建议

##### 2.2.1.12 Batch Review Carousel 模式
- **核心机制**：按复习队列水平滑动 → 每个单元支持快速播/跟读/打字
- **设计思路**：通过批量复习强化学习内容的记忆和巩固

### 2.4 AI对话系统（主导式教练）

#### 2.4.1 学生英文名亲和交互
- **核心规则**：在开场、鼓励、纠错、结算等关键节点重复唤名
- **语音情感参数**：
  - 鼓励场景：情感参数上调
  - 纠错场景：情感参数下调

#### 2.4.2 分层引导逻辑
- **沉默≤5s**：轻提示，例如：“Take your time, [Name]!”
- **超过5s**：句型框架提示，例如：“You can say: I like ____.”（提供可选词汇泡泡）
- **超过8s**：词汇+发音示范，例如：播放“big dog”示范音频并文字高亮
- **超过12s**：影子跟读，例如：AI分步带读：“I saw… a big dog!”

#### 2.4.3 话题降维
- **核心规则**：将抽象话题转化为可选择/填空/图片指引
- **示例**：环保话题→A/B选择原因

#### 2.4.4 语气词动态注入
- **数量要求**：每句含1-2个语气词，占比≥5%
- **位置概率**：
  - 句首：30%
  - 句中：50%
  - 句尾：20%
- **情感语调联动**：与情感语调联动，停顿时间0.3-0.5s
- **常用语气词**：Well…, Hmm…, Uh…等

#### 2.4.5 历史错误融合
- **强制复用**：在对话中强制复用高频错误词/句型，例如“pollution”拼写错误
- **专项微练触发**：
  - 最小对立对：light/night
  - 时态填空：I ____ yesterday

#### 2.4.6 实时纠错
- **语法纠错**：采用三明治反馈（肯定→纠正→鼓励），例如：“Great effort, [Name]! Say ‘went’ instead of ‘go’.”
- **发音纠错**：
  - 音素偏差提示，例如：“Your ‘light’ sounds like ‘night’—tongue lower.”
  - 提供对比音频

#### 2.4.7 对话生成流程
1. 接收用户音频输入
2. 进行语音识别（ASR）
3. 诊断错误
4. 获取用户等级
5. 构建提示词（包含语气词、学生姓名、三明治反馈等）
6. 生成回复文本
7. 转换为情感语音（TTS）
8. 输出音频

#### 2.4.8 提示词工程示例
```
You are a kind English speaking coach. Use casual fillers ('Well…', 'Hmm…', 'Uh…') and sandwich feedback (praise → correction → encouragement). Adapt sentence length to level (basic ≤8 words, advanced ≤15). Mention the student's English name often.
```

#### 2.4.9 性能要求
- 端到端延迟：≤1.2s（缓存命中≤500ms）
- 成本目标：千次对话≤0.8元

#### 2.4.10 容错机制
- 网络异常：离线关卡与提示语缓存（IndexedDB），恢复后自动同步
- API失败：降级至本地模板回复

### 2.5 错误识别与错题课程生成

#### 2.5.1 错误维度
- **核心维度**：听/说/读/写+综合（句子结构）

#### 2.5.2 错误识别格式示例
- **听**：`{type:"listen", phoneme:"θ", confused:"s", word:"think", ts:1.02}`
- **说**：`{type:"speak", word:"light", misheard:"night", phoneme:"n", score:0.62}`
- **读**：`{type:"read", word:"pollution", acc:0.71}`
- **写**：`{type:"write", wrong:"resycle", correct:"recycle"}`
- **综合**：`{type:"grammar", pattern:"past", wrong:"I go yesterday", correct:"I went yesterday"}`

#### 2.5.3 错误上报机制
- **前端交互层统一错误上报接口**：`reportError({ unitId, type, detail, context })`

#### 2.5.4 错误分类枚举
- `SPELLING`：拼写错误
- `VOCAB_MEANING`：词汇含义错误
- `GRAMMAR`：语法错误
- `PRONUNCIATION`：发音错误
- `LISTENING`：听力错误
- `SEMANTIC_INAPPROPRIATE`：语义不当
- `FLUENCY`：流畅度错误

#### 2.5.5 错误记录结构
```ts
interface ErrorRecord {
  id: string;
  unitType: 'word' | 'phrase' | 'sentence' | 'paragraph';
  unitContent: string;
  errorType: ErrorType;
  detail: string; // 描述或 AI 解释
  timestamp: number;
  attemptContext?: { 
    mode: 'listen'|'speak'|'read'|'write'; 
    sourceExerciseId?: string 
  };
  severity: 1|2|3; // 影响程度 (用于加权复习)
}
```

#### 2.5.6 课程生成规则
- **阈值触发条件**：
  - 听：错误率>30%
  - 说：错误率>25%
  - 读：错误率>20%
  - 写：错误率>35%

- **包含内容**：
  - 游戏关卡：错误加权出现
  - 微课视频：口型/要点讲解，音频版可选
  - 练习任务：听写/朗读/仿写/对话

- **推送策略**：
  - 生成时间：每日0点
  - 展示位置：进入“专项训练”栏目
  - 支持特性：离线下载

### 2.7 学习进度跟踪

- 课程完成率
- 单词掌握度
- 学习时间统计
- 错误记录和分析
- 掌握度图谱 (词汇 / 短语 / 语法结构)
- 自适应复习 (Spaced + Weighted Hybrid)：
  - 基础算法: SM2 改良 + 错误权重 (severity) + 遗忘曲线 (基于时间间隔衰减)
  - 调度公式 (概念): 下一复习时间 = 当前时间 + f(历史正确率, 错误次数, 严重程度, 内容等级)
  - 复习优先级 = w1*错误率 + w2*时间衰减 + w3*(1-掌握度)
  - 复习队列生成策略: 保证 70% 弱项 + 30% 新输入 (防止过度重复)

#### A. Listen First + Gradual Reveal (单词学习)

1. 进入单词卡片 → 自动播放标准语音 (可配置 `autoPlayFirst=true`)
2. 初始显示: 下划线或首字母 (e.g. "_pple")
3. 用户尝试输入 → 错误 1 次：可点击“提示 1”显示词性 + 中文释义
4. 错误 2 次：自动慢速重播 + 显示剩余首字母
5. 完成后：显示例句生成按钮
6. 记录：错误次数、hint 层级、完成时间、掌握度更新

#### B. Shadowing Loop (句子跟读)

1. 播放标准语音 → 倒计时 3s → 开始录音
2. 录音结束自动调用 ASR → 与原文比对→ 标出错位/漏读单词
3. 提供“再次跟读”循环按钮 (可设置循环次数上限 n=3)
4. 每轮评分曲线折线图实时更新
5. 支持勾选 "自动下一句" 跳转下一内容

#### C. Type While Listen (听写拼写)

1. 循环播放单词 (默认循环 3 次或直到正确)
2. 用户输入框实时比对：正确字母绿色，错误红色下划线
3. 超时或错误 2 次 → 提供慢速 + 分音节播放 (Spell Mode)
4. 最终正确 → 提示熟练度提升 + 下一个单词预加载

#### D. Speak Then Check (口语组织)

1. 显示主题提示 (e.g. "Describe your morning routine")
2. 用户录音 → ASR 转写 → 语义匹配对比目标关键词表
3. 展示：关键词命中率、语法建议、发音平均分
4. 支持“重新组织”按钮 → AI 给出更地道版本 + TTS 播放

### 6.3 提示(Hint)层级设计

| 层级 | 内容示例 | 触发条件 | 掌握度影响 |
|------|----------|----------|------------|
| Level 0 | 无提示 | 默认 | +正常分值 |
| Level 1 | 词性 + 中文释义 | 错误≥1 或手动触发 | -5% 当次提升 |
| Level 2 | 首字母或音标 | 错误≥2 或手动触发 | -10% |
| Level 3 | 完整拼写显示 (需再输入确认) | 错误≥3 | -20% |
| Level 4 | 例句直接展示 | 用户请求拓展 | 不再提升掌握度，仅加体验分 |

掌握度更新建议: `Δscore = baseGain * (1 - hintPenaltyRatio)`。例如 baseGain=8, hintPenaltyRatio(Level2)=0.1 → +7.2。

| 状态 | UI 表现 | 记录事件 |
|------|---------|---------|
| 待播放 | 播放按钮高亮 | `session_state=idle` |
| 播放中 | 进度条 + 动态波形 | `audio_play_start` |

### 6.6 性能与稳定性考量

- 预加载下一单元音频 (低优先级) 减少等待

- 大批量复习使用虚拟滚动避免主线程阻塞
- 组件粒度拆分：播放、录音、评分结果分离，减少重渲染

## 8. 技术方案

### 8.1 架构与链路

- 音频输入 → ASR（语音识别） → 文本 → 对话引擎（含提示词工程+历史错误融合） → 回复文本 → TTS（情感语音） → 音频输出
- 错误诊断：WhisperX（词级时间戳+音素偏差）与规则引擎联合

### 8.2 架构与链路

- **核心链路**：音频输入 → ASR（语音识别） → 文本 → 对话引擎（含提示词工程+历史错误融合） → 回复文本 → TTS（情感语音） → 音频输出
- **错误诊断**：WhisperX（词级时间戳+音素偏差）与规则引擎联合
- **数据存储**：
  - MongoDB（可选）：用于错误库、学生画像、课程包
  - Redis（可选）：用于提示语与模板缓存

### 8.3 模型选型

#### 8.3.1 ASR（自动语音识别）
- **推荐方案**：
  - 讯飞星火：实时场景
  - Whisper/WhisperX：批转+对齐场景

#### 8.3.2 对话生成
- **推荐方案**：
  - 豆包 Pro：英语口语化+低延迟，适合API调用
  - Qwen-7B：文本质量与可微调性强，可用于学术/离线备用

#### 8.3.3 TTS（文本转语音）
- **推荐方案**：豆包语音合成2.0
- **核心特性**：情感参数≥23，语气词自然

#### 8.3.4 发音诊断
- **推荐方案**：WhisperX small/large混合使用
  - small：低延迟、资源友好（实时反馈场景优先）
  - large：准确率高、抗噪好（考试/复杂口音分析优先）

### 8.4 Whisper vs WhisperX 与 small/large 对比（英语场景）

- **Whisper v4**：高精度通用ASR；不含词级时间戳与说话人分离
- **WhisperX**：工具链增强（词级时间戳、对齐、分离），适合教学纠错
- **small模型**：延迟低、资源友好（实时反馈场景优先）
- **large模型**：准确率高、抗噪好（考试/复杂口音分析优先）
- **推荐使用方式**：
  - small初筛+large疑难
  - 或 v4转录 + X对齐增强

### 8.5 提示词工程

#### 8.5.1 角色设定示例


#### 8.5.2 动态注入策略
- 将学生历史错误（最小对立对、时态、错拼）写入prompt上下文
- 根据沉默时长切换引导等级

#### 8.5.3 缓存策略
- **高频内容**：鼓励与纠错模板本地JSON
- **中频内容**：场景模板Redis
- **低频内容**：动态生成走API

### 8.6 对话生成伪代码

```python
def dialogue_flow(user_audio, student_id):
    text = asr(user_audio)  # iflytek/whisperx
    errors = diagnose(text) # whisperx + rules
    level = get_level(student_id)
    prompt = build_prompt(text, errors, level) # include fillers, name, sandwich
    reply = llm_generate(prompt) # doubao/qwen
    audio = tts(reply, emotion="encouraging")
    return audio
```
