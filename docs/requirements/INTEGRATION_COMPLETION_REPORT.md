## 核心改进亮点

### 🎯 手动编辑器（建议 1.1）
```
支持：
✓ 5 步流程：新建 → 逐句编辑 → 高级功能 → 预览 → 保存
✓ 6 字段：text/translation/phonetic/pos/example/audioMeta
✓ 高级功能：
  - 从音频拖拽生成句子（Descript 风格）
  - CSV 批量导入
  - 音频替换和时间戳精编

预期收益：教师创建 10 句课程从 30 分钟 → 2 分钟
```

### 🔧 补救课程智能策略（建议 1.2）
```
支持 5 类错误自动分类：
┌─ PRONUNCIATION：ASR 置信度 < 60% → 音标强化课
├─ FLUENCY：发音时长异常 → 连读课程
├─ GRAMMAR：句法错误 → 语法课程
├─ VOCABULARY：陌生词汇 → 词汇课程
└─ COMPLETENESS：不完整 → 简化课程

触发规则：5 句错题 → 自动生成补救课程

预期收益：补救课完成率 +40-50%，学习效率 +30%
```

### 📊 学习热力图（建议 3.3）
```
展示维度：GitHub 风格周热力图
├─ 颜色深浅代表练习强度（▯ 无 → ▮ 轻 → ▮▮ 中 → ▮▮▮ 重）
├─ 支持 7/30/90 天自定义周期
├─ 点击日期深入 → 课程名/时长/得分分布
└─ 导出日报告（PDF/CSV）

预期收益：学习可视化 + 激励机制，留存率 +15-25%
```

### 🎛️ 智能状态机（建议 4.3）
```
跟读完整流程状态机包括：
✓ 正常路径：显示句子 → 播放音频 → 录音 → ASR 评测 → 反馈
✓ 用户取消：保存 draft，支持恢复
✓ 网络中断：降级到本地 Sherpa
✓ ASR 失败：最多 3 次重试，超限则跳过
✓ 低置信度：无效录音提示重新录
✓ 并发保护：禁用按钮直到完成
✓ 超时处理：自动中断请求

覆盖边缘情况：7+，容错能力显著提升
```
