# Lexitype Academy 需求列表

## 1. 产品概述

- 基于 React + TypeScript 构建的语言学习应用，支持 Electron 桌面端
- 提供英语听、说、读、写全方面的学习功能
- 采用模块化架构设计，支持多种学习模式和音频处理功能
- 目标：打造覆盖“听、说、读、写”四大能力、可持续迭代的 AI 辅助英语学习与复习体系
