### 实现的完整流程

```
1. 显示句子
   ├─ 英文原文 (大字号)
   ├─ 国际音标 (可选显示)
   └─ 中文翻译 (点击显示/隐藏)

2. 播放示范音频
   └─ 🔊 听示范音 按钮 → TTS 播放标准发音

3. 用户录音
   ├─ 🎤 开始录音 按钮
   ├─ 实时录音时长显示
   └─ ⏹️ 停止录音 按钮

4. ✨ 自动回放用户录音（核心改进）
   ├─ 🎧 自动播放用户刚录制的音频
   ├─ 回放进度条 (0-100%)
   ├─ 🔁 重新听 按钮（回放完成后显示）
   └─ ⏭️ 不需要回放 按钮（延迟 1 秒显示）

5. 评估中
   └─ 🤖 AI 正在评估中... (loading 动画)

6. 结果反馈
   ├─ 总分 (70-100)
   ├─ 准确度、流利度、发音分项得分
   ├─ 错误词汇高亮（得分 < 85）
   └─ 文字反馈

7. 操作选项
   ├─ 🔄 再试一次（得分 < 80 时显示）
   └─ 下一句 → / 完成练习
```

### UX 改进点

#### 1. **增强自觉性**
用户听到自己的录音，能更直观地发现发音问题，类似"照镜子"的效果。

#### 2. **优化信心**
"原来我的发音是这样"，增加学习动力和参与度。

#### 3. **灵活交互**
- **重新听**: 回放完成后可以重复听自己的录音
- **跳过回放**: 延迟 1 秒显示，避免误操作
- **自动进入评测**: 回放完成后自动触发 ASR

#### 4. **心理学价值**
- 提高学习趣味性
- 增加课程参与度
- 建立发音自信心
