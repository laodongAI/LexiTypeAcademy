# AI 工具模块设计规范检查清单

> 本清单用于验证 AI 工具模块是否符合 LexiType Academy 系统设计规范

## 📐 设计规范一致性检查

### 1. 页面布局规范

- [x] **全宽布局**：页面采用全宽设计，无左侧固定边栏
  - ✅ AIToolsOptimizedPage.vue 采用全宽响应式布局

- [x] **内容最大宽度限制**：内容区域最大宽度 1400px，自动居中
  - ✅ `.ai-tools-page { max-width: 1400px; margin: 0 auto; }`

- [x] **顶部标题区**：清晰的页面标题和描述
  - ✅ `.page-header { h1 + p 描述 }`

- [x] **模块间距规范**：模块间距 32px，使用 `el-divider`
  - ✅ `margin-bottom: 32px; <el-divider />`

### 2. 色彩与渐变规范

- [x] **渐变背景**：卡片使用 `linear-gradient(135deg, ...)`
  ```scss
  background: linear-gradient(135deg, rgba(64, 158, 255, 0.05) 0%, rgba(64, 158, 255, 0.02) 100%);
  ```

- [x] **CSS 变量**：使用系统 CSS 变量替代硬编码颜色
  - ✅ `color: var(--text-color);`
  - ✅ `border: 1px solid var(--border-color-light);`
  - ✅ `background: var(--bg-color);`

- [x] **悬停效果**：一致的悬停过渡效果 0.3s
  ```scss
  transition: all 0.3s ease;
  &:hover {
    box-shadow: 0 4px 12px rgba(...);
    transform: translateY(-4px);
  }
  ```

### 3. 组件规范

- [x] **标签页**：使用 `el-tabs` 和 `el-tab-pane`
  - ✅ 标签页卡片风格（`type="card"`）

- [x] **卡片**：使用 `el-card` 组件
  - ✅ 统一的圆角和边框样式

- [x] **表单**：标签位置和样式一致
  - ✅ `label-position="top"` 和 `label-width="auto"`

- [x] **按钮**：统一尺寸和样式
  - ✅ 主操作按钮 `type="primary"` `size="large"`
  - ✅ 次要按钮 `type="default"` 或 `text`
  - ✅ 危险操作 `type="danger"`

- [x] **输入框**：统一的输入框样式
  - ✅ 使用 `el-input`、`el-textarea`、`el-select` 等

### 4. 排版规范

- [x] **标题大小层级**
  - ✅ 页面标题 h1: 28px
  - ✅ 模块标题 h4: 16px
  - ✅ 子标题 h5: 14px

- [x] **字体权重**
  - ✅ 标题：font-weight 600
  - ✅ 标签和按钮：font-weight 500
  - ✅ 正文：默认 400

- [x] **行间距**：正文行间距 1.5 或 1.6
  ```scss
  line-height: 1.5; // 或 1.6
  ```

### 5. 间距规范

- [x] **页面外间距**：20px (响应式 16px)
  - ✅ `padding: 20px;` @media 改为 `padding: 16px;`

- [x] **功能模块间距**：32px
  - ✅ `margin-bottom: 32px;`

- [x] **卡片内间距**：24px 或 16px
  - ✅ 快速启动卡片：24px
  - ✅ 预览卡片：16px

- [x] **表单项间距**：20px
  - ✅ `:deep(.el-form-item) { margin-bottom: 20px; }`
