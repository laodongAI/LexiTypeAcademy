# 单元整体学习与双模式课堂设计 v1

- 日期：2026-10-24
- 状态：实施中；浏览器端到端验证待执行
- 目标：从“先选一个内容类型再进入单课时”升级为“先进入整个单元，按学习流程推进”；同时支持学员自主操作与 AI 老师引导两种课堂模式。

## 1. 产品判断

现有模型是 Course → Lessons → Items；Lesson.contentShape 表达 word/phrase/sentence/passage/dialog，但当前课程详情以课时表为主要入口，学员需要先判断进入哪类内容。这是内容组织视角，不是自然的教学过程。

本版本不拆新内容表、不迁移历史课程；把一个现有 Course 当作“单元学习容器”，按内容形态从现有课时汇总教学材料。已有课堂精读、词燃尽、句子燃尽和词根能力继续作为可复用能力，旧的单课时入口保留。

## 2. 两种学习模式

### A. 自主学习

学员掌握节奏和操作：播放/重播英语材料、按流程切换阶段、查看翻译与词汇、完成阶段小测、获得基于实际作答的即时反馈与得分。不会伪造发音评分；当前版本的自我检查/文本比对只评估文本答案，不宣称专业音素评分。

### B. AI 老师带学

老师围绕整个单元持续引导：说明目标 → 带读短文 → 讲重点句 → 讲重点词 → 解释语法 → 提问并等待学员回答 → 针对回答纠错、追问/复练 → 单元总结。一次只提一个主要问题，不能提前泄露标准答案；反馈应指出学员真实回答中的证据，不得声称尚未完成的学习任务已掌握。

复用现有 `conversationCoreService` 与后端 `/api/ai/chat`，会话消息持久化到已有 `ai_task_logs`，通过 linkedCourseId/contextSummary 关联本单元内容，不新建对话表。AI 教师必须基于单元原始材料；内容缺失时要明确告知，不可编造教材原句。

## 3. 单元教学流程

1. **单元导入**：主题、学习目标、内容概览。
2. **通读短文/对话**：优先 passage/dialog；没有时说明当前单元缺少篇章材料，不伪造原文。
3. **重点句子**：优先 sentence 课时；无独立句子课时则从 passage/dialog 原文拆句展示，但标明“从原文提取”。
4. **重点词汇**：汇总 word/phrase 课时，保留词义、音标、例句等已有字段。
5. **语法讲解**：当前内容模型没有 grammar 类型，因此 v1 由 AI 基于本单元实际句子生成解释/练习，不将生成结果写回原教材；AI 不可用时提示当前阶段需配置 AI，不伪装已有语法资料。
6. **输出与检查**：阶段小测、翻译/复述/句子补全等；答案反馈与得分基于实际提交记录。
7. **总结**：总结已完成阶段、实际作答与下一步建议。

阶段可跳过，但必须明确标记跳过；重新进入单元时恢复阶段和已记录进度。

## 4. 数据与架构边界

- Course/lesson/items 是唯一原始内容源；不新增平行课程模型。
- 自主学习阶段进度使用本地检查点，避免仅因刷新丢失当前阶段；现有学习事件/练习记录仍按其既有契约写入。
- AI 教师会话复用 conversationCoreService；会话与课程关联，AI 历史可恢复。
- 朗读复用 useSpeechPlayer/TTS；跟读评分只有在 ASR/麦克风链路真实接通并实测后才能宣称可用。v1 不把“播放了音频”冒充“完成跟读评分”。
- 不改动既有课程内容；不自动重分类历史 Lesson；旧单课时课堂入口继续可用。

## 5. 验收标准

1. 课程详情提供“开始单元学习”入口，进入后不要求先选单词/句子/段落。
2. 页面提供“自主学习”和“AI 老师带学”两种模式。
3. 自主模式按固定流程覆盖通读、句子、词汇、语法、输出检查；可播放原始内容，阶段测验反馈必须对应真实提交。
4. AI 模式基于当前单元材料逐步教学、等待回答并纠错；消息可持久化并在重新进入时恢复。
5. 没有原文/句子/词汇时显示清晰空状态，不虚构原始教材内容。
6. 进度刷新后可恢复；阶段切换、跳过和完成状态一致。
7. 前端 typecheck/build 与后端 CI 通过；浏览器实际语音、AI 会话恢复和多种课程形态的 E2E 需单独验证并记录，不得仅凭构建通过宣称全链路完成。

## 6. 分阶段

- P0：整体单元入口、双模式、阶段流程、朗读、文本练习即时反馈、AI 老师持久会话。
- P1：接通并验收真实跟读/ASR 评分、阶段性成绩汇总与学习报告。
- P2：根据学习表现动态调序、个性化复习与跨单元间隔复习。


## 实施补充：阶段状态与原文拆句

- 阶段状态区分 `completedStages` 与 `skippedStages`；跳过只用于导航提示，不计入完成率。之后实际完成该阶段时会清除跳过状态。
- 篇章拆句时没有可靠的一句一译对齐数据，因此不把段落级中文翻译挂到第一句；提取句标明来源，避免把原文整段的跟读任务伪装成单句跟读。
- 本补丁需要由新分支的 Frontend quality workflow 再次验证；浏览器/Windows E2E 仍待执行。
