# 课程仓库分级与课堂老师语音引导 v1 设计

**状态**：APPROVED（按 2026-10-24 用户需求实施）
**日期**：2026-10-24
**关联**：`docs/design/classroom-guidance-and-feedback-v1.md`、`project-control/TASKS.md`

## 1. 背景与目标

用户提出三项诉求：

1. 课程生成时选择的音色/语音，需要保证单词与句子都能正常发声；
2. 课程仓库目前只有一层（直接到 Unit），课程变多后会混乱，需要“教材 → 年级上下册 → 单元列表”分级；
3. 课堂需要老师声音引导：根据学员作答反馈、响应超时等状态，决定下一句老师说什么、播放什么，流程自然。

本设计覆盖第 2、3 项；第 1 项属于既有 TTS 链路的校验与修正，不新增交互。

## 2. 课程仓库分级

### 2.1 数据来源

教材课程由 `TextbookImportPanel` 生成，现有字段：

- `tags = ['AI', 'Textbook', publisher, series, unitTitle]`
- `title = '${textbookName} - ${unitTitle}'`
- `description = '${publisher} / ${series}'`

为支持更精确的分级，生成端新增可选标签（向后兼容，历史课程走回退解析）：

- `Textbook:<教材名>`
- `Grade:<年级>`
- `Semester:<上/下>`

前端新增纯函数 `buildTextbookGroups(courses)`：

1. 识别教材课程：`tags` 含 `Textbook`，或 `tags`/描述能解析出“出版社 / 系列”；
2. 解析出版社、系列、教材名、单元名、年级、学期；
3. 无年级/学期信息时，从教材名中按中文年级正则提取（如“三年级上册”）；
4. 输出三级结构：`教材系列（出版社·系列）→ 年级册 → 单元课程`；
5. 非教材课程归入“其他课程”，保持原有卡片/列表视图行为。

### 2.2 界面

课程仓库新增第三种视图 `textbook`（教材视图）：

- 每个教材系列一个分组标题，展示课程数量；
- 系列内按“年级册”卡片排列，卡片头部显示年级册与单元数；
- 卡片内为单元列表：单元序号、单元名、课时数、学习中标记，点击进入课程详情；
- 顶部保留搜索/筛选，教材视图同样受搜索结果约束；
- 教材视图不分页，按分组展示全部匹配课程；
- 原有 `grid` / `list` 视图与批量操作保持不变。

### 2.3 验收

- 生成多个教材单元后，课程仓库可看到“系列 → 年级册 → 单元”三级结构；
- 历史课程（无新增标签）仍能正确归组；
- 点击单元可进入课程详情；
- 非教材课程在“其他课程”区域可见。

## 3. 课堂老师语音引导

### 3.1 状态机

课堂引导为“事件驱动 + 短台词”模型，不引入服务端会话：

| 状态/事件 | 触发 | 老师行为 |
|---|---|---|
| 进入课堂 | 课程/课时加载完成（昵称引导结束后） | 称呼 + 本课目标 + 当前模式玩法，随后可带一次示范音频 |
| 切换模式 | 用户点击模式页签 | 播报该模式玩法（短句） |
| 单元开始 | 燃尽进度变化且 `stage=0`（句子）或进入新单元 | 报题号 + 操作提示，并自动播放该单元示范音 |
| 作答正确 | 燃尽舞台提交正确 | 轮换鼓励短句（不重复最近一条） |
| 作答错误 | 燃尽舞台提交错误 | 简短纠正 + 下一步动作（看提示 / 再听一遍） |
| 响应超时 | 输入区 20 秒无输入/提交 | 第一次提示“先听示范”，第二次提示“查看提示”，第三次建议跳过 |
| 阅读活动 | 精读首次查词 / 加入生词本 | 方法提示（不停读、生词本会复习） |
| 本课完成 | 燃尽全部完成或手动完成 | 一句话总结，随后打开点评卡 |

台词全部为确定性中文模板，按事件轮换；不调用 AI，避免课堂延迟与不可控。

### 3.2 语音与字幕

- 复用 `useSpeechPlayer` 与现有 TTS 引擎/音色；老师台词语言显式设为 `zh`；
- 播放器新增 `language` 选项，默认 `en`，保证既有调用不变；
- 老师台词以“字幕气泡”常驻课堂底部：头像、当前台词、重播、静音；
- 语音失败时仅保留文字，不阻塞课堂；
- 老师台词优先级高于示范音：新台词会打断上一段，避免多音轨。

### 3.3 事件扩展

`BurnDownStage` 新增：

- `answer`：`{ correct, expected, input, unitKey, unitIndex, stage, mode }`
- `idle`：`{ count, unitKey, unitIndex, stage }`（输入区空闲触发，最多两次升级）

`ReaderStage` 新增：

- `activity`：`{ type: 'lookup' | 'add-word', word, matched? }`

父页面 `ClassroomPage` 负责把事件翻译成台词，子舞台不直接持有老师逻辑，避免双份实现。

### 3.4 防打扰规则

- 同一台词去重窗口 8 秒；
- 鼓励/提醒类台词最小间隔 1.2 秒；
- 用户切换模式或提交答案时，立即打断旧台词；
- 离开课堂时停止语音与定时器。

### 3.5 验收

- 进入课堂后听到/看到老师开场与玩法说明；
- 燃尽答对、答错、超时均有不同台词，且超时会逐级升级提示；
- 单元开始时老师报题并自动播放示范音；
- 精读首次查词、加入生词本有对应提示；
- 底部字幕气泡可重播、可静音；
- TTS 不可用时文字照常显示；
- `npm run build` 通过。

## 4. 不在本版范围

- AI 个性化台词生成；
- 跨课时的长期学习记忆播报；
- 语音识别跟读评分；
- 家长/教师端远程引导。
