## 1. 产品判断

英语学习不应继续以孤立页面和零散按钮堆叠功能。建议把现有能力组织成一致的数字课堂：学习首页负责明确下一步；统一课堂承载词汇、句子、跟读、短文听读和 AI 引导；学习闭环记录真实完成、错误、跳过和复习状态。

本次优先解决两个 P0：
1. 跟读时音频、当前句、高亮和滚动位置同步，用户不必手动寻找正在播放的句子。
2. AI 引导学习采用固定黑板/舞台，而不是让整页随着聊天记录和长讲解不断向下延伸。

这是基于用户反馈与现有设计材料形成的产品判断。当前真实页面布局、TTS/ASR 运行状态与各视口问题，本轮尚未在目标 Windows 应用中观察，需实施前复核。

## 2. 用户价值与成功信号

| 问题 | 用户损失 | 预期变化 |
|---|---|---|
| 跟读位置不同步 | 视觉搜索打断听读对应 | 当前句自动定位并高亮，切句/暂停/重播状态一致 |
| AI 教学像长网页 | 当前目标与下一步不清楚 | 固定课堂框架，当前教学内容成为视觉中心 |
| 各能力流程割裂 | 用户自己决定学习顺序 | 共享进度、语音状态、反馈和恢复机制 |
| 完成、跳过、失败混淆 | 学习成果不可信 | 状态分别记录，不把跳过当完成、播放当跟读或单次答对当长期掌握 |

初期先验收交互正确性，不预设没有数据支持的提升百分比。后续用户测试可测任务完成率、错误/重复操作次数、耗时、提示理解度和主观负担，并报告样本与局限。

## 3. 项目知识与复用边界

既有设计 `docs/design/unit-learning-modes-v1.md` 已定义自主学习与 AI 老师带学；交接记录提及 `UnitLearningPage.vue`、`ClassroomPage.vue`、`ReaderStage.vue`、`useSpeechPlayer`、`conversationCoreService` 与后端 `/api/ai/chat` 等能力。实施前必须重新读取当前主干代码和路由确认调用关系；这些路径来自既有设计/交接，不代表本轮已核验所有实现。

- 复用既有 Course → Lessons → Items 模型、播放器、AI 会话与学习记录。
- 不新增平行课程/对话/音频数据库，不自动覆盖教材原文。
- 不新建第二套音频播放通道。
- 只有存在可靠词级时间戳才可做词级高亮；否则先做句级同步。
- 现有文本相似度不能描述为专业发音评测。
- 不一次性重写首页、所有课堂和面试页。

## 4. 统一课堂信息架构

1. **顶部状态区**：返回/退出、课程/单元、当前阶段与进度。
2. **中央黑板/主教学区**：当前句、词汇、短文片段、问题或场景，占主要视觉空间。
3. **教师引导区**：当前指令、提示或反馈；长解释可展开，历史对话默认折叠。
4. **底部操作区**：仅显示当前阶段适用的播放、录音、提示、提交、重试、上一步/下一步。
5. **辅助区**：释义、词卡、历史和设置按需展开；窄屏改为抽屉或分阶段显示。

固定的是框架和操作位置，不是强迫所有内容塞进一屏。长文应在主教学区内部滚动或分段呈现；页面外壳和主要操作区不应随消息不断下移。建议主黑板优先、辅助侧栏可折叠，而非永久右侧聊天栏。

## 5. 跟读同步规格（P0-A）

### 状态模型
统一管理当前句 ID/索引、播放状态（idle/loading/playing/paused/ended/error）、播放任务令牌、自动推进偏好、录音/识别状态和同步精度（sentence/word）。旧音频或旧请求的延迟事件不得覆盖新句状态；当前句不应由多个组件各自维护。

### 行为规则
- 开始播放：当前句进入可视区并高亮。
- 播放中：当前句保持可读；仅在当前句离开可视区域或进入跟读模式时定位，避免反复滚动和抖动。
- 用户主动滚动：允许查看上下文，不持续抢回滚动；提供“回到当前句”。
- 手动选句：当前句、音频、进度和高亮同步切换。
- 暂停：保留当前句，不自动跳句。
- 重播/切句：音频与高亮同步，旧事件无效。
- 跟读/录音模式默认等待用户完成或操作，不在用户准备回答时强制跳句。
- 录音中、识别中、识别失败、识别不确定和有效结果分别显示。
- 音频失败时保留当前句并提供重试，不伪装成功。
- 无可靠时间戳时只做句级高亮；不能用文本切分位置冒充真实词级时间。

### 必测场景
连续播放至少 10 句；快速切句；暂停/恢复；重播；手动滚动与返回当前句；TTS 失败；麦克风拒绝；ASR 超时；切句时旧请求返回。检查双音频、旧高亮、滚动抖动和意外跳句。

## 6. AI 老师黑板与教学状态机（P0-B）

### 教学流程
按内容类型适配，而不是每次机械走完全部阶段：
1. 导入目标；
2. 示范讲解；
3. 一次一个问题的引导练习；
4. 基于真实回答的反馈；
5. 重练/提示/重听；
6. 新语境迁移；
7. 总结与复习建议。

AI 必须基于当前单元真实教材内容。缺少原文时明确说明，不编造教材原句。答错时指出一项最重要的问题并给可执行重试动作；识别不确定与学习错误必须区分。

### 布局规则
- 当前目标、教材内容和当前问题是主视觉。
- AI 历史记录可查看但默认折叠，不成为整页主内容。
- 长解释可展开；长文章在黑板内部滚动或分段展示。
- 操作区按状态变化：示范时播放/继续，答题时输入/录音/提交，反馈时重试/看提示/下一步。
- 不同时展示所有工具，不适用的按钮隐藏或禁用并解释。
- 等待输入、录音中、处理中、反馈、重试、跳过、完成、失败和恢复均须有明确状态。
- 退出、暂停、继续和结束不能混为一谈；若任务仍在后台运行，必须明确告知。
- 默认不在用户说话或录音时插播长反馈；支持静音、重播、提示、跳过和退出。

状态至少区分 `not_started`、`in_progress`、`awaiting_user`、`processing`、`completed`、`skipped`、`interrupted`、`failed`。实施前核对既有数据模型，优先复用进度与会话持久化，不为 UI 状态盲目新增表。

## 7. 不同内容类型的教学方法

| 类型 | 教学流程 | 关键操作 |
|---|---|---|
| 词汇 | 听音 → 语境理解 → 主动回忆 → 使用 → 间隔复习 | 显示/隐藏释义、重听、提示、回忆作答 |
| 句子/跟读 | 示范 → 同步阅读 → 跟读 → 有依据反馈 → 重练 | 高亮、重播、录音、重试 |
| 短文/听力 | 整体理解 → 分段听读 → 精听 → 理解检查 → 复述 | 分段定位、语速、显示/隐藏文本 |
| AI 教学 | 目标 → 示范 → 单题引导 → 反馈 → 重试 → 迁移 → 总结 | 提示、回答、重答、暂停/退出 |
| 口语/面试 | 场景目标 → 用户表达 → 追问/反馈 → 重答 → 总结 | 录音状态、反馈依据、示范答案 |

统一的是课堂骨架、进度、语音、反馈和恢复；不同任务保留不同教学策略。

## 8. 视觉与设备规则

- 遵循项目既有设计 Token、控件与间距，不引入第二套主题。
- 视觉优先级：当前材料/问题 → 当前操作/回答 → 提示/反馈 → 进度 → 辅助信息。
- 减少同等权重卡片、装饰和常驻工具；让用户不必先理解界面才能学习。
- 桌面优先主教学区；窄屏辅助区改为抽屉/弹层/分阶段呈现。
- 检查长句、长单词、长 AI 回复、虚拟键盘、操作遮挡、横向溢出、焦点可见和键盘可达性。
- 关键操作不依赖悬停；输入框内方向键、空格和 Esc 不得被课堂快捷键误拦截。

## 9. 分阶段实施

### P0-A：跟读同步可靠性
核对真实入口、播放器与时间戳；建立单一当前句状态和播放任务令牌；实现自动定位、高亮、手动选句、暂停、重播和失败恢复；新增状态测试并执行真实浏览器 TTS/录音回归。

### P0-B：AI 黑板布局
先在真实窗口记录当前滚动、消息、内容区和操作区；以现有单元学习页与课堂组件为基础决定复用方案；保留既有 AI 会话和课程上下文；固定课堂外壳，长内容内部滚动或分步呈现；覆盖加载、等待、处理、反馈、重试、跳过、完成、失败与恢复状态。

### P1：统一流程与学习记录
统一阶段语义、完成/跳过状态和真实学习事件；连接词汇、句子、短文与口语的复习闭环；不破坏原始教材。

### P2：个性化与效果评估
根据真实练习表现调整复习与练习顺序；区分正确率、回忆表现、长期复习与口语迁移；获得合适用户样本后再评估效果。

## 11. 实施前未知项

1. 当前跟读页面的真实组件、播放器事件和句子标识。
2. TTS 是整段还是分句音频；是否有可靠句级/词级时间戳。
3. 麦克风与 ASR 当前是完整接通、部分接通还是占位。
4. AI 老师实际路由、主要组件与会话恢复范围。
5. 固定操作区/内容区内部滚动对桌面壳、窄屏和 Web 的兼容性。
6. 当前学习进度与 AI 会话持久化契约能否满足恢复需求。
7. 真实教材中的空内容、长句、长文章、缺少翻译和音频失败场景。

每个切片记录任务 ID、基线章节、用户价值、交互取舍、文件范围、测试命令、CI/提交、真实运行环境与视口、前置数据、步骤、预期/实际、截图/日志及遗留风险。

## 13. 建议产品决策

- D1：统一课堂框架，保留各教学方法差异。
- D2：首版跟读采用可靠的句级同步；词级同步以真实时间戳为前提。
- D3：AI 教学采用固定黑板/舞台；长内容在内容区内部滚动或分步展示。
- D4：默认让用户掌控节奏；自动跳句、播报和纠错必须可预测、可控。
- D5：优先复用现有课程、播放器、AI 会话和学习记录，不建设平行基础设施。
- D6：跟读同步与 AI 黑板分别作为独立 P0 切片验收，不一次性大重构。
