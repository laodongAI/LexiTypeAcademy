# AI 英语课堂体验重构 V1

- 状态：首轮 UI 改造已提交；真实窗口验收 NOT_RUN
- 日期：2026-10-26
- 适用入口：`/courses/:courseId/learn` → AI 老师带学

## 1. 产品决策

AI 老师带学应进入全屏沉浸式课堂，而不是作为普通课程页中的内嵌聊天区域。仓库已有 `ClassroomPage.vue`，但它面向单课时精读/燃尽/词根；单元 AI 老师课堂有不同学习对象与交互，因此本轮先重构现有入口，不强行合并两种课堂。

## 2. 本轮实现

- AI 老师区域通过 Vue Teleport 挂载到 body，使用全屏 dialog 语义，覆盖应用主导航。
- 增加显式“退出课堂”和 Escape 退出，退出只关闭课堂界面，不删除会话。
- 主讲解区独立滚动；课堂历史折叠并限制高度；回答区作为独立底部区域，避免长回复把输入框推离视口。
- 增加可见键盘焦点样式。
- 朗读当前讲解根据文本是否包含中文字符选择 zh/en。中英混合文本仍是单一语音策略，后续应考虑按句分段。
- “我的学习”明确管理实际课程进度、最近学习与待复习；“学习计划”明确管理目标、排期、每日任务和打卡。

## 3. 设计原则

1. **沉浸优先**：课堂应覆盖主应用导航，减少与教学无关的视觉干扰。
2. **一个主任务**：当前讲解是视觉中心，历史按需查看，作答入口稳定可见。
3. **可退出、可恢复**：关闭 UI 不等于结束或删除 AI 会话；再次进入复用现有活跃会话。
4. **数据职责清晰**：计划是目标与安排，学习记录是实际发生的行为；本轮不合并数据模型。
5. **不夸大 AI 能力**：当前回复仍是自由文本，尚未完成结构化教学步骤、状态机和评价协议。
