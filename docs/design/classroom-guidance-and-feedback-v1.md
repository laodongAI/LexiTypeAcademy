# 课堂引导与学习点评 v1（P0）设计

**状态**：APPROVED（按 2026-10-24 对话确认的第一版范围实施）
**日期**：2026-10-24
**关联**：`docs/design/settings-tabs-and-model-config-v1.md`、`project-control/TASKS.md`

## 1. 目标与范围

把课堂从"学完即结束"升级为"有称呼、有肯定、有记录"，并降低课堂操作成本。本版只做 P0：

1. 昵称引导（首次进入课堂，可跳过，设置页可改）
2. 课堂键盘导航（精读 ←/→ 切句，燃尽 ←/→ 切题，Esc 退出输入态）
3. 课堂完成点评（1–5 星 + 三句话点评 + 语音朗读）
4. 点评记录落库（复用 `learning_records.metadata`）

**不做（后续版本）**：开机自动语音引导、完成自动语音播报、AI 个性化点评、学习报告趋势页、跨学段语气模型。

## 2. 现状与约束

- 本地单用户、无登录体系 → 昵称入口不能挂在登录事件上，改为"首次进入课堂"的引导层。
- 燃尽舞台已有"单元完成 700ms 后自动进入下一单元"，本版保留并补"上一题/下一题"。
- 课堂完成弹窗已存在，仅展示 3 个统计数字，本版升级为点评卡。
- 学习记录表已有 `metadata` JSON 字段（`learning_records.extra_metadata`），点评不需要新增表。
- 语音合成走现有 TTS 服务，点评朗读复用当前设置的引擎与音色。

## 3. 交互规格

### 3.1 昵称引导

- 触发：进入课堂且本地昵称为空。
- 形式：阻塞式对话框，说明"小老师会这样称呼你"，可"以后再说"。
- 校验：去首尾空格，长度 1–12；允许中文、英文、数字、下划线。
- 存储：`localStorage` 的 `lexitype-settings` 新增 `nickname` 字段。
- 修改：设置 → 通用 → 学习身份。
- 语气：产品内称"学习小老师"，不冒充真人。

### 3.2 键盘导航

| 按键 | 精读 | 句子燃尽 / 词燃尽 | 词根 |
|---|---|---|---|
| `←` | 上一句并朗读 | 上一题（重置该题阶段） | 不接管 |
| `→` | 下一句并朗读 | 下一题（未完成则跳过并提示） | 不接管 |
| `Space` | 播放当前句 | 播放参考发音（未聚焦输入框时） | 不接管 |
| `Enter` | 展开当前句词卡 | 提交答案 | 不接管 |
| `Esc` | 关闭词卡 | 退出输入态 | 不接管 |

拦截条件：焦点在 `input/textarea/contenteditable`、`e.isComposing`、`e.repeat`、带 `Ctrl/Meta/Alt` 时不处理方向键。

可见性：课堂底部常驻快捷键提示条，首次进入高亮 3 秒。

### 3.3 完成入口

- 燃尽：全部单元完成自动触发。
- 精读 / 词根：顶栏提供"完成本课"按钮，手动触发。
- 触发后统一打开点评卡。

## 4. 点评规格

### 4.1 星级（1–5）

| 维度 | 依据 | 加分 |
|---|---|---|
| 完成度 | 完成单元 / 总单元 ≥ 60% | +1 |
| 完成度 | 完成单元 / 总单元 = 100% | +1 |
| 独立度 | 提示使用次数 / 单元数 ≤ 20% | +1 |
| 首答质量 | 首次即正确的单元 ≥ 70%（燃尽） | +1 |
| 阅读质量 | 查词次数 / 已读句数 ≤ 1（精读） | +1 |

完成即保底 1 星；速度不计分，只作为文字描述。

### 4.2 文案结构

```
① 称呼 + 具体肯定
② 一个真实观察（表现或问题）
③ 一个下一步动作建议
```

模板按星档与模式（燃尽/精读/词根）选择并轮换；不生成不存在的优点。

### 4.3 语音朗读

点评卡提供"听小老师说"按钮，调用现有 TTS 朗读完整点评；不自动播放，避免打扰。

## 6. 语音化路线（v2 预告）

- 开机引导："上次学到哪里、今天完成什么"，进入首页后可选自动播报。
- 完成播报：点评卡出现后自动朗读，设置页提供"自动语音引导"开关。
- 复用现有 TTS 与引擎/音色配置；无 TTS 资源时降级为文字。

## 7. 验收标准

- 首次进入课堂出现昵称引导，跳过后不再重复；设置页可修改并即时生效。
- 精读 ←/→ 能切句并朗读、滚动到可视区；燃尽 ←/→ 能切题；输入态方向键不冲突。
- 燃尽完成与"完成本课"均打开点评卡，展示 1–5 星与三句话点评。
- 点评可朗读，且不阻塞完成流程（TTS 失败仅提示）。
- 点评记录成功写入后端，`metadata.stars` 与界面一致。
- `npm run build` 通过。
