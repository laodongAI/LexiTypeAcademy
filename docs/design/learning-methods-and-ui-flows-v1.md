# 英语学习方法全景盘点与逐方法交互流程 v1

- 日期：2026-10-26
- 状态：STATIC_REVIEW / PROPOSED；方法清单基于当前 main 可读取的设计与前端实现，不代表所有端到端能力均已实测。
- 本文目标：明确“学什么（内容类型）”“怎么学（教学方法）”“在哪里学（产品入口）”三者的关系；逐一描述教学流程、UI 流程、AI/音频依赖和验收标准，作为后续统一课堂改造的基线。

## 1. 产品结论：内容不是方法，入口不是流程

当前系统至少有三组概念需要分开：

1. **学习内容**：单词、短语、句子、短文/文章、对话、语法重点、单元/课程。
2. **学习方法**：词汇记忆（词燃尽）、句子精练（句子燃尽）、精读/阅读器、词根学习、听写、跟读、模仿发音、翻译输出、AI 老师带学、自主单元学习、间隔复习、错题复练，以及练习中心中的打字/拼音工具。
3. **产品入口**：课程仓库/课程详情、单元整体学习、课时练习、复习系统、练习中心、AI 工具。

不应把每个内容类型都变成一个独立的一级菜单；应从内容入口选择合适方法，再由统一课堂承载任务。方法不适用时解释原因，而不是让用户进入后才发现无法学习。

## 2. 当前方法与实现盘点

| 方法/能力 | 主要内容对象 | 目标与学习流程 | 当前入口/代码证据 | AI、语音和数据边界 |
|---|---|---|---|---|
| 单元整体自主学习 | 整个课程/单元 | 目标导入 → 通读 → 重点句 → 重点词 → 语法 → 输出检查 → 总结 | `UnitLearningPage.vue`；`docs/design/unit-learning-modes-v1.md` | 阶段进度与跳过状态必须分开；不把跳过计入完成 |
| AI 老师带学 | 单元及关联教材内容 | 目标 → 示范讲解 → 一次一个问题 → 等待回答 → 基于回答反馈 → 重练/迁移 → 总结 | `UnitLearningPage.vue`、`conversationCoreService.ts` | 复用已有 AI 会话；必须引用真实教材上下文；服务失败要可重试；AI 评价不应直接冒充掌握度 |
| 精读/阅读器 | 篇章、对话、较完整句子 | 整体理解 → 按段/句阅读 → 点读/查词 → 翻译辅助 → 重点理解 → 自测/复述 | `learningMethodCompatibility.ts` 中 `reader`；阅读器组件与单元通读阶段 | 原文必须可追溯；整段翻译不能伪装成每句的精确翻译；播放/高亮只在同步证据支持的粒度上呈现 |
| 词燃尽 | 单词、短语 | 看/听目标 → 理解词义 → 主动回忆 → 拼写/识别 → 语境使用 → 复习 | `learningMethodCompatibility.ts` 中 `burn-word`；相应课堂路由 | 释义、音标、例句来自教材/词典真实字段；无字段时明确缺失，不由 UI 或 AI 伪造 |
| 句子燃尽 | 完整句子 | 听示范 → 理解结构 → 关键片段练习 → 主动复现 → 反馈 → 再练 | `learningMethodCompatibility.ts` 中 `burn-sentence` | 必须有可练的完整多词句子；文本比对不等于专业发音评分 |
| 词根课堂 | 有明确词根/词根组数据的单词 | 词根含义 → 词形构成 → 同根词对比 → 例词辨析 → 回忆检测 | `learningMethodCompatibility.ts` 中 `root` | 只有真实词根元数据才可启用；不能把词性或拼写相似误称为词根关系 |
| 跟读 | 句子、独立短句/短语（按能力边界） | 老师示范 → 用户准备 → 录音 → 识别/评价 → 针对性反馈 → 重练 → 下一项 | `FollowMode.vue`、`LessonPracticePage.vue` | 自动领读需要验证浏览器自动播放策略；评分必须以实际录音/ASR/评价返回为依据；失败时不能显示成功分数 |
| 模仿发音 | 句子或可朗读短语 | 听标准音 → 录音 → 回放对照 → 评价 → 重点重练 | `ImitationMode.vue` | 不得展示随机生成的装饰波形冒充真实音频波形；准确度/流畅度等分数必须有真实算法或服务依据 |
| 听写 | 单词、短语、句子 | 听音 → 输入听到的内容 → 提交 → 对照答案/相似度 → 纠错 → 再听/下一题 | `DictationMode.vue` | 答案比对可评文本差异；音频失败、空答案、重复提交要有明确状态 |
| 翻译输出 | 中文提示与对应英文原文 | 读中文 → 独立写英文 → 提交 → 查看参考答案/差异 → 修改或下一题 | `TranslationMode.vue` | 参考答案应来自课程原文；相似度只是文本相似，不自动代表语义完全正确 |
| 间隔复习 | 到期词条/复习队列 | 回忆答案（先不泄露）→ 自评/答题 → 记录结果 → 更新下次复习 → 下一项 | `ReviewPage.vue`、review store | 当前 `DueWord` 字段缺少释义/音标/例句，必须先关联真实词典/课程条目，不能以掌握等级代替答案 |
| 错题复练 | 历史错误题/错误记录 | 看错因 → 再次作答 → 对比正确答案 → 针对性提示 → 复练 → 退出或加入复习队列 | `AdaptivePracticeCenterPage.vue`、`ErrorReviewPanel.vue` | 错误来源、正确答案与题目来源必须可追溯；暂无数据时显示空状态而不是伪造题目 |
| 自适应练习/推荐 | 课程内容与练习记录 | 选择课程/目标 → 推荐适配方法 → 用户确认 → 练习 → 反馈 → 根据实际记录给建议 | `AdaptivePracticeCenterPage.vue`、`AdaptiveRecommendations.vue` | 推荐理由可解释；不应在没有真实学习证据时声称“薄弱项”或“AI 已掌握” |
| 快速练习 | 词汇/输入/听写等短任务 | 选练习目标 → 选模式/难度 → 做题 → 结果 → 再练/退出 | `QuickPracticePanel.vue`；旧版 `PracticeCenterPage.vue` | 当前旧版部分入口存在“功能开发中”的提示，应隐藏、禁用或明确标注，不能呈现为已可用功能 |
| 打字/拼音工具 | 字符、键盘输入或拼音内容 | 选择工具/难度 → 练习 → 反馈/统计 | `PracticeCenterPage.vue`、相关工具标签页 | 与英语课程学习区分定位；不应占用英语学习主流程的核心入口 |
| 课堂学习进度 | 阶段、课时、练习事件 | 开始 → 进行 → 完成/跳过/中断/失败 → 恢复 | `UnitLearningPage.vue`、学习事件服务 | “播放过”“看过”“提交过”“答对”“掌握”是不同事实，不能用一个 completed 字段替代 |

### 2.1 当前已知产品风险

1. 方法清单散落在内容兼容规则、课时练习页、单元学习页、复习页和练习中心；用户要自己理解入口间关系。
2. “跟读”和“模仿”表面操作高度相似，但教学目标、评价证据和下一步动作没有在入口层清晰区分。
3. 复习系统目前缺少完整词条答案字段；在补齐关联前无法提供专业的词汇回忆闭环。
4. 练习中心存在旧版入口/工具入口与课程练习混杂的问题；部分快捷入口仍可能是未完成占位。
5. 音频播放、录音、ASR、AI 反馈、文本相似度是不同能力，不得统一包装成一个含糊的“AI 评分”。
6. “单元整体学习”是编排多个方法的学习旅程，不应再复制出一套独立词汇、句子、阅读练习逻辑。

## 3. 内容类型 × 学习方法适配矩阵

| 内容类型 | 默认路径 | 可选路径（满足前置条件） | 不应直接提供 |
|---|---|---|---|
| 单词 | 词汇学习/词燃尽 | 词根学习（存在真实词根数据）、听写、间隔复习、拼写练习 | 直接进入篇章精读；无词根数据时进入词根课堂 |
| 短语 | 词汇学习/词燃尽 | 听写、跟读（有可播放内容且录音链路可用） | 词根学习默认入口；长篇精读 |
| 句子 | 句子精练/句子燃尽 | 跟读、模仿、听写、翻译输出、阅读器语境理解 | 无完整句子时启动句子燃尽 |
| 短文/文章 | 精读/整体理解 | 单元通读、听力理解、从原文提取句子/词汇后学习 | 未经用户确认自动把原文重分类为独立词汇课 |
| 对话 | 对话整体理解/精读 | 句子跟读、听写、角色扮演（后续独立设计） | 把精读宣称为口语角色扮演 |
| 整个单元 | 单元整体学习（自主或 AI 老师） | 课程内的词汇、句子、阅读、输出、复习 | 要求用户先挑一种内容类型才能开始单元 |
| 到期复习词条 | 间隔复习 | 释义回忆、拼写、例句填空（有真实数据时） | 没有释义/例句数据时生成貌似权威的假答案 |
| 错题 | 错题复练 | 按错误类型切换听写/翻译/跟读等 | 无历史错误证据时伪造错题队列 |

适配判断必须由同一个注册表驱动入口卡片、课堂导航和直接 URL。内容缺失时，解释原因并给可行替代项。

## 4. 每种方法的标准 UI 流程

### 4.1 单元整体自主学习

1. **入口页**：显示单元主题、内容摘要、预计步骤、真实可用材料概况；主按钮“开始单元学习”。
2. **模式选择**：自主学习/AI 老师带学；说明两者差别，不把所有阶段挤在选择页。
3. **课堂壳层**：顶部单元名称、返回/退出、阶段进度；中央材料；底部固定主要操作。
4. **阶段流**：通读 → 重点句 → 重点词 → 语法 → 输出检查 → 总结。无材料阶段显示“本单元暂无此类材料”，可跳过但跳过不算完成。
5. **反馈**：提交答案后展示参考答案、用户答案、差异与下一步；未提交前不泄露答案。
6. **完成**：汇总真正完成、跳过、作答结果与待复习项；允许继续学习或退出。
7. **恢复**：重新进入恢复最后有效阶段；退出、跳过、完成、失败状态分别记录。

### 4.2 AI 老师带学

1. 进入后先建立/恢复与当前单元关联的会话。
2. 老师用一句话说明目标与当前阶段，再呈现真实教材内容。
3. 每轮只提出一个明确问题；提供文本输入/语音输入时明确标识当前支持哪种。
4. 用户提交后显示处理中状态，禁止重复提交造成重复消息。
5. 回答反馈分为：做对了什么、需要修正什么、一个可执行重试动作。
6. 允许“给提示、再试一次、重听、跳过、暂停/退出”；长历史默认折叠。
7. 只有在用户真实回答或练习记录支持时，才记录评价证据；AI 生成建议不能自动提升长期掌握度。
8. 服务超时/断网时保留输入和会话，允许安全重试并避免重复追加用户消息。

### 4.3 阅读/精读

1. 显示标题、来源、原文与翻译可见性。
2. 默认先整体阅读，不强制逐句打断。
3. 点选句子后再展示词汇/句子辅助信息；没有对齐翻译时明确标注“全文译文”。
4. 播放时高亮与音频同步；用户主动滚动后暂停自动跟随，提供“回到当前句”。
5. 通过理解题、复述或重点句练习验证理解；阅读完成不等于已掌握。
6. 空文章、空句子、音频失败均有明确恢复路径。

### 4.4 词汇学习/词燃尽

1. 显示一个目标词，避免同时铺开大量答案。
2. 第一步先听/看词形，再允许查看释义；释义来自原教材或已关联词典。
3. 用例句说明语境；若无例句，不自动把 AI 临时生成内容标成原文。
4. 隐藏答案后进行回忆/拼写/选择等主动练习。
5. 根据实际作答反馈，区分正确、部分匹配、错误和未作答。
6. 用户选择掌握程度/答题结果后才安排复习；播放过一次不能算掌握。
7. 无释义/音标时显示缺失字段与可用替代动作。

### 4.5 句子精练/句子燃尽

1. 先展示原句及来源，再播放示范。
2. 解释一个核心结构/搭配，避免一次展示过多语法点。
3. 通过句子补全、重组、翻译或复述让用户主动产出。
4. 需要口语时进入跟读/模仿子任务，不把文本答对等同于发音正确。
5. 反馈指出具体差异，提供重试和参考答案。
6. 完成后给下一句或回到单元阶段，不另造独立进度体系。

### 4.6 跟读

1. 进入句子时显示“老师示范”状态，自动请求播放；若浏览器阻止自动播放，提供明确的“点击播放示范”按钮与原因提示。
2. 示范期间显示当前句并同步高亮；提供重听、语速（若服务支持）和退出。
3. 示范结束后提示开始录音，用户明确触发录音，显示麦克风权限/录音中/停止录音状态。
4. 提交后显示识别/评价中状态，防止重复提交。
5. 结果展示实际可用的评分证据；ASR 不可用、录音过短或结果不确定时不显示伪分。
6. 结果后提供“针对性重练”和“下一句”；方向键需与焦点/录音状态兼容，不在输入文本时抢占按键。
7. 自动下一句默认关闭，避免跳过用户反馈与准备时间。

### 4.7 模仿发音

1. 明确目标是“听标准音并模仿”，与跟读的逐句流程相似但重点是回放对照。
2. 展示标准音播放状态与用户录音状态；录音前不能展示用户波形。
3. 只有真实音频分析生成的波形才标注“波形”；没有波形能力时展示清楚的状态面板。
4. 用户可以播放标准音、录音、播放自己的录音、提交评价。
5. 评价仅展示当前服务真正支持的指标；若底层只有文本匹配，应标明“文本识别匹配”，不能伪装音素级评分。
6. 允许重录和比较后再继续。

### 4.8 听写

1. 播放音频，默认隐藏目标英文答案。
2. 用户输入听到的单词/句子；支持重听和逐级提示。
3. 提交后锁定本次答案，展示用户输入、参考答案和归一化差异。
4. 文本相似度不是听力理解的唯一指标；大小写/标点差异应按题型规则处理。
5. 错误时提供再次聆听、提示、查看解释和下一题。
6. 记录作答事件与题目来源；音频失败时不允许提交空题或伪造结果。

### 4.9 翻译输出

1. 显示中文提示，不提前显示英文参考答案。
2. 用户独立输入英文；支持草稿保留与提交。
3. 展示参考答案、用户答案、文本差异和语法/表达建议。
4. 仅在简单标准答案比对时使用“匹配度”；开放翻译如存在多种正确表达，需要 AI 评价且明确其不确定性。
5. 支持修改重答、查看提示和下一题。

### 4.10 词根学习

1. 先确认该词条有真实词根、词缀与词义来源。
2. 以词根/词缀解释构词，再展示同根词与语义联系。
3. 通过辨析题验证是否理解构词和语义，而不是只记住字母相似。
4. 无可靠词根数据时禁用入口并解释原因；不可用词性分组替代。

### 4.11 间隔复习与错题复练

1. 先显示本轮目标数、来源和预计时间，不把全部统计都塞进卡片。
2. 先要求主动回忆，再显示答案；卡片正反面有清晰语义。
3. 当前条目至少应能关联词形、释义、来源；有音标/例句时展示。
4. 用户作答或自评后记录结果，更新调度；“跳过”不算掌握。
5. 完成本轮后显示本轮实际完成数、正确率/自评统计、错题和下一步建议。
6. 无有效会话时统计显示“—”，不能把缺失数据显示为 0%。
7. 错题必须来自真实作答记录，显示错误原因/原题和正确答案；无历史数据时显示可解释空状态。

### 4.12 自适应练习、快速练习与工具型练习

1. 首页首先询问目标或提供有证据的推荐，不先罗列大量模式。
2. 推荐卡必须说明原因（例如来源课程、到期复习或最近真实错误）。
3. 用户确认后进入对应任务的专用 UI，沿用该方法标准流程。
4. 完成后返回统一结果/进度，不在快速练习、课时练习和单元学习里各自复制一套统计。
5. 打字/拼音工具与英语内容练习在导航上区分，未完成入口必须隐藏或明确标注开发中。

## 5. 统一课堂 UI 结构

- **顶部**：返回/退出、课程/单元/课时、当前任务、进度；避免标题区过高。
- **中央主教学区**：当前唯一主要材料/问题；按任务提供文章、句子、词卡、听写输入或 AI 黑板。
- **教学辅助区**：释义、例句、提示、AI 反馈、历史对话，按需展开，不与主任务抢视觉权重。
- **底部固定操作区**：当前阶段最重要的 1 个主按钮，最多 2 个次操作；状态变化时更新按钮语义。
- **状态反馈**：idle/loading/playing/recording/processing/feedback/completed/skipped/interrupted/failed；错误提示说明原因与下一步。
- **窄屏**：辅助区改抽屉/分步；主按钮保持可达；不让长文、历史消息把主操作推到屏幕外。
- **键盘与无障碍**：可见焦点、合理 tab 顺序、Esc 退出弹层、方向键不干扰文本输入/录音；对话窗口进入时焦点移入，退出恢复。

## 6. 统一学习事件与事实边界

推荐事件至少区分：
- `learning_stage_started`
- `content_viewed`
- `audio_playback_completed`
- `recording_submitted`
- `answer_submitted`
- `answer_evaluated`
- `feedback_viewed`
- `stage_completed`
- `stage_skipped`
- `session_interrupted`
- `session_resumed`

事件应关联 courseId、lessonId、itemId（可用时）、method、source、时间、评价证据和请求/尝试 ID。不要仅存一条模糊的“学习完成”。AI 自述、音频播放成功或页面打开不等于学习者掌握。

## 7. 优先级与实施计划

### P0：统一认知与防误导
- 本文作为学习方法清单与 UI 流程基线。
- 修复所有伪 UI/占位入口，明确哪些方法可用、哪些有前置条件。
- 所有方法入口使用统一适配注册表；每个方法卡展示适用内容、目标和大致步骤。
- 修复复习卡片真实词条数据关联前，不宣称复习闭环已完成。
- 对跟读/模仿的真实录音、ASR、评价边界进行实测并按证据展示。

### P1：统一课堂外壳
- 统一顶部进度、主教学区、辅助区、底部操作、加载/错误/恢复状态。
- 方法内部保持不同教学策略，不强迫不同任务共享同一套内容组件。
- 复用既有播放器、AI 会话、练习事件和课程数据；禁止建立平行数据源。

### P2：真实个性化
- 以实际作答事件和可追溯数据驱动推荐。
- 引入文章拆句/提词学习副本时保留源课时、原文定位和版本关系；不覆盖原教材。
- 音素/角色扮演/高级口语等能力先独立定义教研流程、数据契约与评价边界，再实现。

## 8. 验收清单

- [ ] 从课程内容进入时，系统根据真实内容推荐可用方法，并解释不适用原因。
- [ ] 单词、短语、句子、篇章、对话和单元均有明确的默认学习路径。
- [ ] 每种方法都有入口、主流程、空状态、加载/错误、完成与恢复 UI 规则。
- [ ] AI 老师每轮只提一个主问题，回答反馈与真实回答关联。
- [ ] 跟读自动播放失败时有用户可操作的回退；录音/ASR 失败不显示伪分。
- [ ] 模仿界面不使用随机装饰冒充真实波形。
- [ ] 复习答案来自真实词典/课程关联，缺失时明确显示，不编造。
- [ ] 跳过、播放、提交、答对、完成和掌握的语义严格区分。
- [ ] 练习中心无未完成却可点击的假入口；统计有真实数据来源。
- [ ] 前端单测、类型检查、生产构建通过。
- [ ] Windows/浏览器桌面、窄屏、键盘、TTS/ASR 与 AI 失败恢复完成真实 E2E；未实测项目标记 NOT_RUN。
