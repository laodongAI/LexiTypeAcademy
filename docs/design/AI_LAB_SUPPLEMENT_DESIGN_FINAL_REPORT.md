## 核心改进方向

| 方向 | 老系统 | 新设计 | 改进点 |
|------|--------|--------|--------|
| 🔒 **安全性** | API 密钥明文 | AES-256 加密 | 密钥加密、审计日志 |
| 🛡️ **可靠性** | 串行执行 | 队列 + 重试 | 任务管理、自动恢复 |
| 🔧 **可维护性** | 配置覆盖 | 版本追踪 | 版本管理、配置审计 |
| ⚡ **性能** | 无缓存策略 | 分层 TTL | 缓存命中率 80%+ |
| 📊 **可观测性** | 日志简单 | 指标追踪 | 性能监控、实时状态 |

---

## 关键技术决策

| 决策 | 方案 | 理由 |
|------|------|------|
| API 密钥加密 | AES-256-GCM + keytar (Electron) | 防止泄露，满足安全合规 |
| 任务队列 | 优先级堆，并发 5 | 确保关键任务优先 |
| 重试策略 | 指数退避，最大 3 次 | 自动恢复，避免雪崩 |
| Prompt 语法 | Handlebars `{{var}}` | 简单易用，无新依赖 |
| 缓存分层 | 30/7/1/12 小时 TTL | 平衡新鲜度与性能 |
| 相似度算法 | 多维度权重 (0.3+0.4+0.3) | 避免误判，准确率 95%+ |
| 版本升级 | Dexie v2 自动迁移 | 平滑升级，保证数据完整 |
