# 练习模块功能审计与修复记录（2026-10-24）

## 1. 审计范围与证据边界

审计对象为主路由 `/practice`（`AdaptivePracticeCenterPage.vue`）及其快速启动、课程练习、错题复习、复习队列、统计、课时练习组件和相关 Store。检查方式为当前 `main` 分支源码与项目已有产品规范的静态调用链审查。

- 代码审查可以确认事件是否连接、是否存在占位逻辑、数据是否来自持久化接口。
- GitHub Actions 只能证明 CI 环境中的类型检查/构建结果。
- 浏览器实际点击、麦克风权限、真实 TTS/ASR、Windows 本机集成尚需运行验收；本文不把静态审查等同于端到端通过。

## 4. 练习模块建议的目标学习闭环

1. **选目标**：从课程、错题或听说能力弱项进入，说明本次训练目标与预计时长。
2. **准备检查**：确认课时内容非空；听力检查音频可播放；口语检查麦克风权限和 ASR 可用性。
3. **示范与练习**：提供标准发音、分句重播、慢速播放；口语支持先听示范再录音。
4. **即时反馈**：指出具体差异，区分识别不确定、内容错误与发音问题，不把 ASR 失败当作低分。
5. **巩固闭环**：答错项目进入错题队列；高频错题触发短练习；掌握后降低复习频率。
6. **结果与恢复**：保存题量、正确数、耗时、模式和错误项；退出后能恢复课程位置；统计只读取真实持久化数据。

## 5. 推荐优先级

- **P0（本次）**：修复听力/口语无响应；保证快速练习入口可进入实际课时；移除固定错误率示例；统计读取真实记录并暴露加载错误。
- **P1（下一步）**：修复统计图表的固定示例数据；将错误 ID 映射为实际英文题目；完善错题复习与课程间隔复习队列的数据契约。
- **P1（验收）**：用真实课程完成听写、跟读、翻译、模仿四种模式；验证音频、麦克风、ASR、结果持久化、退出与重进。
- **P2（教学质量）**：按 CEFR/课程类型调整练习长度和提示强度；为听力增加“先听大意→关键词→逐句听写”的渐进路径；为口语增加“听示范→跟读→录音回听→具体反馈→重练”的闭环。
