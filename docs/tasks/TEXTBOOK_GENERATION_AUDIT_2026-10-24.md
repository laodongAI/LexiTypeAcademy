## 已发现并修复

1. **导航与真实进度**
   - 主用面板之前按完整单元计数，单元内已成功的内容类型不会立即反映在进度条中；现按“单元 × 内容类型”显示已完成项，并另列完整单元计数。
   - 当前单元/内容类型写入检查点；页面重新进入后恢复步骤、进度和当前任务。
   - 旧版生成组件从教材选择进入单元解析时显式执行解析，避免步骤已前进但列表尚未加载。

2. **默认选择**
   - 主用面板的 `parseUnits` 原先自动选择全部单元；现改为默认不选，需用户明确勾选。
   - 旧版生成组件的缓存命中与重新解析也改为默认不选。

3. **增补单元与增补内容类型**
   - 主用面板增加“补充单元”入口，手动添加的单元会进入本次选择，并写入年级隔离的目录缓存和任务检查点，后续重新进入也能看到。
   - 生成前按当前出版社、系列、教材和单元定位已有课程；匹配课程和保存合并时均使用教材身份标签、出版社/系列或严格一致的旧版标题+描述，不再只凭相同标题跨教材复用。
   - 已有内容类型会跳过；新增类型追加到当前单元课程，保存时沿用既有课程合并逻辑。
   - 每个内容类型成功后立即记录检查点；空结果不被标记为成功，失败后可重试。

4. **耗时与性能**
   - 根因之一是生成请求串行：每个单元最多需要单词、句子、短文、语法、发音多次独立 AI 调用；启用音频时还会为词/句/短文逐项请求 TTS。总耗时随单元数、内容类型数和模型响应时间累加。
   - 主用面板现对单元生成使用最多 2 个并发 worker，等待所有 worker 收尾后再报告错误，避免失败后仍有未跟踪的后台 worker。
   - 出版社系列、教材目录和单元目录的并发请求增加去重；年级筛选复用系列教材目录缓存。
   - 单元缓存按出版社、系列、年级、教材名称隔离；不把无法确定所属年级的旧缓存直接复用于新年级，避免错归类。
   - 尚未进行不同模型、并发限制、输出 token 与 TTS 组合的真实压测；如出现上游限流，可将并发从 2 调低。

5. **后台运行与断点恢复**
   - 主用面板按内容类型持久化已完成任务和已生成课程草稿；页面路由切换不主动取消当前异步流程，重新进入可观察运行状态，完成后恢复预览。
   - 刷新或异常退出后，当前未完成请求会被视为中断；已完成内容类型保留，用户可重新触发生成以跳过完成项并继续。
   - 生成进度、当前单元/类型与手动补充单元都纳入检查点。
   - 旧版组件使用独立检查点键，避免与主用面板的任务结构互相覆盖。

## 尚存限制与风险

- 这是浏览器前端的可恢复任务，不是后端常驻任务队列。关闭浏览器/标签页、浏览器崩溃或清理站点数据时，正在进行的单个 HTTP 请求无法从中间 token 继续；恢复会重试该内容类型。
- 检查点保存在当前浏览器的 localStorage，不保证跨设备、跨浏览器或清理站点数据后恢复。
- 多并发仅限制在两个单元，尚未根据实际 provider 限流和模型性能自动调参。
- 浏览器端真实生成、跨路由运行、刷新后恢复、增补课程合并、手动新增单元与音频生成仍需端到端验收。
