# P0 改进实施清单与验收标准

> 关联基线：[PRODUCT_IMPROVEMENT_BASELINE.md](./PRODUCT_IMPROVEMENT_BASELINE.md)  
> 版本：V1.0 / 2026-10-24

## 目标

先修复影响产品可信度和主要学习路径的问题，再扩展新的 AI 能力。每个任务必须有独立验收证据。

## P0-01 首页内容可信度

- **问题**：首页包含中文学习文案、固定学习统计、固定课程、固定任务。
- **用户价值**：不再把演示值误认为真实个人学习数据。
- **实施要求**：
  - 删除与英语学习无关的文案和课程示例。
  - 在真实统计数据源接入前，不显示伪造的学习天数、词汇数、准确率。
  - 在任务数据模型尚未接入前，不用可勾选的静态任务伪装真实任务；展示明确的空状态与下一步入口。
  - 首页应引导用户进入课程仓库或现有学习入口。
- **验收标准**：
  - [ ] 首页无中文学习文案或虚构课程。
  - [ ] 没有真实数据时，显示诚实的空状态。
  - [ ] 所有主按钮能进入已存在的正确路由。
  - [ ] 页面在窄窗口下不发生明显溢出。
- **测试**：前端类型检查、构建；人工启动首页核对文案与跳转。

## P0-02 首页继续学习路由

- **问题**：旧逻辑跳转 `/courses?id=<id>`，与当前详情路由结构不一致。
- **实施要求**：
  - 课程详情必须使用 `/courses/:courseId`。
  - 只有在存在真实学习记录时，才展示继续学习；后续恢复课时/位置由统一学习进度服务提供。
  - 不应以课程 ID 替代课时位置恢复能力。
- **验收标准**：
  - [ ] 课程详情路由与首页入口一致。
  - [ ] 不存在对应课程时有可理解的回退路径。
  - [ ] 恢复学习位置需要有真实数据支持，不可硬编码。
- **测试**：路由单测或人工验证课程详情、旧路由兼容和无数据场景。

## P0-03 学习计划能力边界

- **问题**：当前路由注释说明计划 UI 已有，但数据模型待实现。
- **实施要求**：
  - 盘点计划页组件、持久化服务、数据库模型与 API。
  - 如果数据闭环尚未实现，标注为预览/开发中或从核心学习流程中暂时降级入口。
  - 定义计划、每日任务、完成事件、跳过/补学、重新安排的数据契约。
- **验收标准**：
  - [ ] 用户可清楚判断计划功能是否可用。
  - [ ] 创建、编辑、完成和删除状态能持久化（若宣布已实现）。
  - [ ] 页面状态与实际保存数据一致。
- **测试**：创建/编辑/重启恢复/删除/重复操作验证。

## P0-04 TTS 无声端到端诊断

- **问题**：静态代码不足以确定无声根因。
- **实施要求**：
  - 依次观测模型可用、合成成功、音频文件有效、URL 可访问、前端取得音频、浏览器播放成功。
  - 诊断结果区分模型不可用、合成失败、URL/HTTP 错误、音频解码错误、播放被浏览器拒绝、播放被取消。
  - 统一音频调度应防止重复播放、旧音频残留和取消后状态不复位。
  - URL 播放失败时，只有在响应中存在有效音频数据时才尝试 Blob 兜底。
- **验收标准**：
  - [ ] 默认引擎的健康状态独立于其他引擎可用状态。
  - [ ] WAV 响应文件头和可解码性经过验证。
  - [ ] 音频 URL 返回预期状态码与 MIME。
  - [ ] 用户点击播放后可看到明确状态；失败有可操作提示。
  - [ ] 快速切换句子、连续点击、停止播放、卸载页面均不会留下卡住的播放状态。
- **测试**：后端 TTS 单测/接口测试；前端服务测试；Windows 实机播放验证。未在实机验证前不得标记 VERIFIED。

## P0-05 真实学习进度和事件来源

- **问题**：各页面可能各自维护状态，需确认是否共享统一数据源。
- **实施要求**：
  - 盘点课程、课时、练习、复习、统计和首页的数据源。
  - 定义学习事件的最小契约：开始、完成、回答、错误、复习、退出/恢复。
  - 页面统计只能消费真实持久化事件；不得从 UI 临时状态推导长期掌握度。
- **验收标准**：
  - [ ] 首页、我的学习、统计页对同一课程的进度一致。
  - [ ] 刷新和重启后关键状态保持一致。
  - [ ] 任务未完成、跳过、失败与成功有明确区别。
- **测试**：同一课程跨页面更新、刷新、重启及重复事件验证。

## 建议实施顺序

1. P0-01 首页内容可信度（小范围、可快速验证）。
2. P0-02 路由正确性与无数据状态。
3. P0-03 学习计划能力边界盘点。
4. P0-04 TTS 端到端诊断（需实际运行环境）。
5. P0-05 统一学习事件与进度（先审计数据契约，再开发）。
